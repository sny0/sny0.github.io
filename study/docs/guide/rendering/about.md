# このWikiについて

## 目的

このWikiは、ゲームプログラマが **レンダリングエンジニア / ゲームエンジン開発者** レベルの知識を身につけるための体系的教材です。単なるAPIリファレンスや技術メモではなく、次の3つの問いに答えることを目的としています。

1. **GPUはどう動いているのか** — ハードウェアの実際の挙動から理解する
2. **なぜその技術が生まれたのか** — 歴史的背景と、置き換えた技術を知る
3. **技術同士はどう繋がっているのか** — 断片ではなく一つの知識体系として捉える

最終的な到達目標は、**Unity・Unreal Engine・DirectX12・Vulkan を「内部で何が起きているか」まで理解して使いこなせること**です。

## 各ページの構成

すべての技術ページは、原則として次の構成に従っています。

| セクション | 内容 |
|---|---|
| 概要 | その技術の一言での説明 |
| なぜ必要なのか | 動機。この技術がないと何が困るか |
| 歴史・誕生した背景 | いつ、誰が、何のために生み出したか |
| それ以前の技術 | 置き換えられた技術と、その限界 |
| 解決した課題 | 何がブレイクスルーだったか |
| 現在の位置づけ | 2020年代の実務でどう使われているか |
| 内部動作 | ハードウェア・ドライバレベルでの動作原理 |
| Unity / Unreal / DX12 / Vulkan での扱い | 4つの主要環境での具体的な対応物 |
| コード例 | 実際に動く形のコード断片 |
| 前提知識と次に読むべきページ | 知識ツリー上の位置 |
| 理解度チェック | 理解を確認する問題(解答付き) |
| 参考資料 | 原典論文・公式ドキュメント・定番書籍 |

## 読み方

- **順番に読む場合**: [学習ロードマップ](/guide/rendering/roadmap.html) の推奨順序に従ってください。第1章→第2章→第3章は全ての土台です。
- **辞書的に使う場合**: 上部の検索ボックス(全文検索)から。各ページ冒頭の「前提知識」を辿れば、足りない知識に戻れます。
- **歴史から入る場合**: [リアルタイム3D技術全史](/guide/rendering/timeline.html) から。技術の進化の流れを掴んでから各論に入ると、個々の技術の「なぜ」が見えやすくなります。

## 表記について

- 数式は $\LaTeX$ 表記でレンダリングされます。例: $L_o = \int_\Omega f_r \, L_i \, (\omega_i \cdot n) \, d\omega_i$
- 図は Mermaid で記述されており、ダークモードにも追従します。
- コード例は HLSL / GLSL / WGSL / C++ / C# を文脈に応じて使い分けます。
- API名は DirectX 12 → **DX12**、Unreal Engine → **UE** と略すことがあります。

## メンテナンス方針

このWikiは「一度完成したら終わり」ではなく、**成長し続けるドキュメント**として設計されています。

- 1ページ = 1技術トピック。新技術(新しいGI手法、新しいアップスケーラ等)は新ページとして追加し、既存ページの「関連ページ」から接続する
- 章の追加・再編成は `docs/.vitepress/config.mts` のサイドバー定義を変更するだけで完結する
- ディレクトリは章単位 (`gpu/`, `math/`, `pipeline/`, ...) で分割されており、ページの移動はリンクの一括置換で対応できる
