キューを一手ずつ動かす

公開ページでは、キューの処理を1つのスレッドで順番に呼び出します。枠は4つあり、空と満杯を区別するために1枠分を残します。

進む順番は 0 → 1 → 2 → 3 → 0 です。

  1. 枠 0 空き
    R 読むW 書く
    →
  2. 枠 1 空き
    R 読むW 書く
    ↓
  3. 枠 2 空き
    R 読むW 書く
    ←
  4. 枠 3 空き
    R 読むW 書く
    ↑

R は次に読む位置、W は次に書く位置です。「空き」は、その枠に未読データがない状態を表します。

満杯と折り返しを試す手順
  1. 「入れる」を3回押して、10、20、30を入れます。
  2. もう一度「入れる」を押すと、満杯のため40が保留されます。
  3. 10を取り出してから40を入れると、W が3から0に戻ります。
  4. 20を取り出してから50を入れると、枠0が再利用されます。残りは30、40、50の順に取り出せます。
