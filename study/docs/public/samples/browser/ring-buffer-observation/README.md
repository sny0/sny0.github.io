# リングバッファとSPSCキューを観察する

[公開サンプル](https://sny0.com/study/samples/browser/ring-buffer-observation/index.html)の上段は、4個のスロットを持つキューの操作画面です。通常の `ArrayBuffer` を使い、「入れる」と「取り出す」で同じキュー実装を順に動かします。「最初に戻す」で空の状態からやり直せます。[図解と仕組み](https://sny0.com/study/browser/spsc-ring-buffer.html)

| 操作 | 観察すること |
| --- | --- |
| 10、20、30を入れる | 3件を保持し、4個目のスロットが空いていても満杯になります。 |
| 40を入れようとする | 満杯の間は追加を断り、既に入れた値を保持します。 |
| 10を取り出してから40を入れる | スロット3に40が入り、次の書き位置が0へ戻ります。 |
| 20を取り出してから50を入れる | 空いたスロット0を再利用します。取り出し順は30、40、50です。 |

## 実際のWorkerで共有する

この `README.md` と `index.html`、`styles.css`、`main.js`、`ring-buffer.js`、`ring-worker.js`、`server.py` を同じフォルダに保存します。Python 3.8以降で次を実行します。

```powershell
python server.py
```

ブラウザのアドレスバーで `http://127.0.0.1:4188/` を開き、「2つのWorkerで実行」を押します。生産側が1から12を順に入れ、消費側が受け取った順番を検査します。各Workerから完了報告が届いたら、件数、順序が一致したか、最後に受け取った値が表示されます。実行ごとに新しい共有バッファを使います。

満杯または空のときは、各Workerがタイマーで再試行します。再試行回数は実行順やタイマーで変わります。公開ページで利用できる順次操作と、実際の並行実行では使うバッファを分けています。

付属サーバーは指定したファイルだけをIPv4ループバックで配信し、ページとWorkerの応答にクロスオリジン分離用のヘッダーを付けます。終了時はCtrl+Cを押します。[実践手順とコード](https://sny0.com/study/practice/browser/ring-buffer-observation.html#run-locally)
