# Wasmへのデータの受け渡しとメモリ確保

[公開サンプル](https://sny0.com/study/samples/browser/wasm-abi-observation/index.html)では、Wasmの関数で領域を確保し、JavaScriptから同じメモリにバイト列を書きます。呼び出し時の長さは、配列では要素数、UTF-8ではバイト数を使います。[実践手順とコード](https://sny0.com/study/practice/browser/wasm-abi-observation.html)

## 手元で試す

`index.html`、`styles.css`、`main.js`、`arena.wasm` を同じフォルダに置き、Python 3で配信します。

```powershell
python -m http.server 4186 --bind 127.0.0.1
```

`http://127.0.0.1:4186/index.html` を開きます。停止するときは端末でCtrl+Cを押します。

## 観察の順番

1. 「インスタンスを作り直す」で始めます。線形メモリは65,536バイト、確保カーソルは1024です。
2. 「i32配列を渡す」を押します。開始位置1024へ `[10, -2, 32]` の12バイトを書き、`sum_i32(1024, 3)` が40を返します。カーソルは1036です。
3. 「UTF-8の文字列を渡す」を押します。開始位置は8バイト境界の1040にそろいます。`A猫🎮` はJavaScriptではUTF-16コード単位が4つ、コードポイントが3つ、UTF-8では8バイトです。`sum_u8(1040, 8)` はバイトの数値の合計1322を返します。
4. 「1ページ分を確保」で失敗を確認します。戻り値は0で、カーソルと線形メモリの大きさは変わりません。
5. 「メモリを1ページ増やす」で、線形メモリを131,072バイトにします。この時点でカーソルは同じです。再度「1ページ分を確保」を押すと、追加した空きに領域を取れます。
6. 「アリーナをリセット」で、カーソルが1024へ戻ります。メモリの容量と生のバイトはそのままです。リセット前に取得した領域の使用期間はここで終わります。

もう一度「インスタンスを作り直す」を押すと、初期状態から観察できます。

## WATから組み立てる

配布の `arena.wat` と同じフォルダで、Node.jsの `npx` を使ってWABTで組み立てます。

```powershell
npx --yes --ignore-scripts --package=wabt@1.0.39 wat2wasm arena.wat -o arena.wasm
```
