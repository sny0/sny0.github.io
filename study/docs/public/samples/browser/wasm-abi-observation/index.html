Wasmへのデータの受け渡しとメモリ確保

Wasmで領域を確保し、JavaScriptでバイト列を書きます。Wasmの関数には開始位置と長さを渡します。

実験を始める

arena.wasm を読み込みます。この教材のアリーナは位置1024から始まり、確保の開始位置を8バイト境界にそろえます。

この実験をHTTP(S)で開き、JavaScriptを有効にしてください。
