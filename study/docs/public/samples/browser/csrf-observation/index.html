同一サイトでもオリジンは異なる

アプリ側の送信元は http://127.0.0.1:4190、別オリジン側は http://127.0.0.1:4191 です。この組み合わせではサイトは同じで、ポートが違うためオリジンは異なります。両方のフォームから送るPOSTにCookieが付く設定です。

このモデルでは、アプリ側のフォームだけがサーバーから受け取ったトークンを持ちます。「追加検査なし」と比べると、Origin照合やトークン照合が状態変更を止める位置が分かります。
