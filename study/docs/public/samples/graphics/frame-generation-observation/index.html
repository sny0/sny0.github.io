フレーム生成で動きと入力の反応を比べる

ロボットの移動を見ながらフレーム生成を切り替えます。次に色を切り替えて、入力が表示に現れるまでを比べます。

描画の設定
この教材ではcanvasを使います。

Canvasを準備しています。

等速時は両方とも毎秒30回、入力を読み取って基礎フレームを作ります。生成オンでは中間を1枚ずつ挟み、毎秒60枚の表示を予定します。
