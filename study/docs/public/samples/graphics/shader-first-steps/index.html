シェーダーで三角形の位置と色を変える

三つの頂点を渡して描画します。横位置は頂点シェーダー、色はフラグメントシェーダーで計算します。UV表示の赤はU、緑はV、青は0.25です。

この教材ではcanvasを使います。

見比べるところ

      
    
        
  • 横位置を変えると、三角形は動き、UVの色は形についていきます。
    • 
        
  • 同じ色の表示に変えると、全体が同じuniform値から作った色になります。
    • 
        
  • 色を掛けると、赤・緑・青の各成分が変わります。
