# TAAを切り替えて床のちらつきとゴーストを比べる

市松模様の床と黄色い物体を描きます。カメラだけを動かして床のちらつきを、物体だけを動かしてその後ろの床に出るゴーストを比べます。[TAAの記事](/graphics/postprocess/taa.html)で、どの色を履歴から読むかを図解しています。

<a href="/study/samples/graphics/taa-observation/index.html" target="_self">TAAの比較デモを開く</a>

## カメラを動かして床を比べる

1. **カメラを横に動かす**をオンにします。**物体を横に動かす**はオフにします。
2. TAAオフで、黄色い物体から離れた床の奥を見ます。カメラの横移動に合わせて、模様が細かく明滅します。
3. **TAAをオンにする**を選び、数フレーム分の履歴がたまるまで少し待ちます。同じ場所を見て、模様の明滅がどれだけ弱くなるか比べます。

描画解像度と床のポイントサンプリングは共通です。TAAをオンにすると、サンプル位置をわずかにずらし、床の同じ位置を過去のカメラへ再投影した結果を混ぜます。[フィルタリングの実践](/practice/graphics/texture-filtering-observation.html)では、テクスチャから読む範囲を変える方法も試せます。

## 物体を動かしてゴーストを比べる

1. カメラの移動を止め、**物体を横に動かす**をオンにします。TAAをオフにして、黄色い物体が通った直後の床を見ます。
2. TAAをオンにし、**異なる面の履歴を捨てる**をオフにします。動く物体の後ろに黄色が薄く残る場所を探します。
3. **異なる面の履歴を捨てる**をオンにします。床の上に残っていた黄色がどう変わるか、同じ移動で見比べます。

ゴーストの観察用に、初期設定では、画面内の再投影先に異なる面の色があっても混ぜます。面の検証を有効にすると、床、物体、背景の区別を使い、前後で面が一致しない場所の履歴を捨てます。履歴色を周囲の画素から補間するため、輪郭付近には色が少し残る場合があります。

**履歴を消す**を押すと、カメラと物体の位置を保ったまま、蓄積をやり直せます。TAAをオンにした状態で試すと、現在のサンプルから始まり、フレームが進むにつれて見え方が落ち着く様子を観察できます。

## WebGL 2で履歴を保存する

| 設定 | 現在のフレーム | 画面に出す色 |
| --- | --- | --- |
| TAAオフ | 基準のサンプル位置で描く | 現在色 |
| TAAオン | ジッタを加えた位置で描く | 履歴を使える画素は現在10%・履歴90%。履歴を使えない画素は現在色 |

履歴画像を2枚用意します。1枚から前フレームまでの蓄積結果を読み、もう1枚に今回の結果を書きます。次のフレームでは2枚の役割を入れ替えます。背景の床はカメラの動きで、黄色い物体はカメラと物体の両方の動きで再投影します。[ピンポンと履歴バッファ](/graphics/postprocess/ping-pong-and-history.html)

## 理解度チェック

1. TAAをオンにすると、遠くの床の色は何を使って決まりますか。

   ::: details 解答
   ジッタを加えた位置で取った現在色と、同じ面を前フレームへ再投影した先の履歴色です。使える履歴を混ぜると、1フレームだけの色の変化が弱まります。
   :::

2. 物体が通った後の床で、履歴から黄色が見つかるのはなぜですか。

   ::: details 解答
   前フレームの同じ場所では物体が床を覆っていました。再投影した画面座標には、現在見えている床の色の代わりに、当時見えていた物体の色が保存されています。
   :::
