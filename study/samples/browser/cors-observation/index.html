結果の読み方

  • basic と cors は本文を読める応答です。opaque の 0 は、実際のHTTPステータスを隠した値です。
  • Fetchが拒否されたとき、JavaScriptにResponseは渡りません。通信とCORSのどちらで失敗したかは、DevToolsのNetworkやローカル実験サーバーのログで確認できます。
  • すべての取得で credentials: "omit" を指定します。CORSの許可ヘッダーは配信元の応答で変わります。
