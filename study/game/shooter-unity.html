シューティング実装例 — C#とUnity 6 ​

設計の考え方と共通仕様をUnityへ接続する例です。APIの基準はUnity 6の6000.0系・2D Built-In Render Pipelineとし、実コンパイルは6000.3.27f1で確認しました。C++版と同様に、ルールを持つModelから描画APIを呼びません。

ShooterModel.csは通常のC#コードです。ShooterDemo.csだけがMonoBehaviourとしてUnityの入力・時間・カメラ・SpriteRendererと接続します。表示用の丸、カメラ等を実行時に用意するため、外部の画像やPrefabは不要です。

シーンを準備する ​

  1. Unity 6で2DのBuilt-Inプロジェクトを用意します。別の作業中シーンとは分けた、小さな確認用シーンを使います。
  2. 次の2ファイルをAssets/Shooter/等へ保存し、コンパイルの完了を待ちます。ShooterDemo.csというファイル名を維持してください。
  3. 空のGameObjectを1個作り、Transformを初期値にしてShooterDemoをアタッチします。同じデモを複数個置かないようにします。
  4. Playして、Gameビューをクリックし、キーボード入力のフォーカスを当てます。
  5. 矢印/WASDで移動、Space長押しで射撃、Rで最初からやり直します。
  • ShooterModel.cs
  • ShooterDemo.cs
  • README.md

URPの2Dテンプレートでは、使用するRendererとSpriteのMaterial等の前提が変わります。この例の起動条件と同一とは扱わず、UnityのレンダラーとSRPも参照してください。

入力の設定 ​

Input Systemが有効な構成ではKeyboard.currentを使い、旧Input Managerが有効な構成ではInput.GetKey等を使います。コードはコンパイル条件でこれらを分けます。両方が有効ならInput System側を使います。

Player SettingsのActive Input Handling、Input Systemパッケージの有無とコードの前提を合わせてください。Input Systemを使う場合の入力更新はProcess Events In Dynamic Updateを前提にしています。Input System側の説明は公式1.11系の導入手順を参照しています。片方のAPIを無条件に呼ぶコードにすると、入力設定が異なるプロジェクトで動かない原因になります。

Modelの全コード ​

Modelは位置・弾・敵・HP・スコアを持ちます。UnityのTransformやGameObjectの参照を、ゲームの状態の代わりにはしません。

csharp
using System;

namespace Sny0.Study.Shooter
{
    // Pixel coordinates: origin at the top-left, positive Y points down.
    public readonly struct ShooterInput
    {
        public float MoveX { get; }
        public float MoveY { get; }
        public bool Shoot { get; }
        public bool Restart { get; }

        public ShooterInput(float moveX, float moveY, bool shoot, bool restart)
        {
            MoveX = moveX;
            MoveY = moveY;
            Shoot = shoot;
            Restart = restart;
        }
    }

    // A value copy for a view. No writable reference into the model is exposed.
    public readonly struct ShooterActor
    {
        public float X { get; }
        public float Y { get; }
        public float Radius { get; }

        public ShooterActor(float x, float y, float radius)
        {
            X = x;
            Y = y;
            Radius = radius;
        }
    }

    public sealed class ShooterModel
    {
        public const float Width = 640f;
        public const float Height = 720f;
        public const float TickSeconds = 1f / 60f;
        public const float PlayerRadius = 18f;
        public const float BulletRadius = 5f;
        public const float EnemyRadius = 16f;
        public const int MaxBullets = 64;
        public const int MaxEnemies = 32;

        private const float PlayerSpeed = 280f;
        private const float BulletSpeed = -520f;
        private const float EnemySpeed = 110f;
        private const int ShotIntervalTicks = 9;       // 0.15 seconds
        private const int SpawnIntervalTicks = 39;     // 0.65 seconds
        private const int InvulnerabilityTicks = 48;   // 0.8 seconds
        private static readonly float[] SpawnX = { 64f, 160f, 256f, 352f, 448f, 544f };

        private struct Actor
        {
            public float X;
            public float Y;
            public bool Alive;

            public Actor(float x, float y)
            {
                X = x;
                Y = y;
                Alive = true;
            }
        }

        private readonly Actor[] _bullets = new Actor[MaxBullets];
        private readonly Actor[] _enemies = new Actor[MaxEnemies];
        private int _bulletCount;
        private int _enemyCount;
        private int _shotCooldown;
        private int _spawnCountdown;
        private int _invulnerability;
        private int _nextSpawnX;

        public float PlayerX { get; private set; }
        public float PlayerY { get; private set; }
        public int HP { get; private set; }
        public int Score { get; private set; }
        public bool GameOver { get; private set; }
        public int ElapsedTicks { get; private set; }
        public bool Invulnerable { get { return _invulnerability > 0; } }
        public int BulletCount { get { return _bulletCount; } }
        public int EnemyCount { get { return _enemyCount; } }

        public ShooterModel()
        {
            Reset();
        }

        public void Reset()
        {
            PlayerX = 320f;
            PlayerY = 650f;
            HP = 3;
            Score = 0;
            GameOver = false;
            ElapsedTicks = 0;
            _bulletCount = 0;
            _enemyCount = 0;
            _shotCooldown = 0; // The first held shot can fire immediately.
            _spawnCountdown = SpawnIntervalTicks;
            _invulnerability = 0;
            _nextSpawnX = 0;
            Array.Clear(_bullets, 0, _bullets.Length);
            Array.Clear(_enemies, 0, _enemies.Length);
        }

        public ShooterActor GetBullet(int index)
        {
            if (index < 0 || index >= _bulletCount)
                throw new ArgumentOutOfRangeException(nameof(index));
            Actor actor = _bullets[index];
            return new ShooterActor(actor.X, actor.Y, BulletRadius);
        }

        public ShooterActor GetEnemy(int index)
        {
            if (index < 0 || index >= _enemyCount)
                throw new ArgumentOutOfRangeException(nameof(index));
            Actor actor = _enemies[index];
            return new ShooterActor(actor.X, actor.Y, EnemyRadius);
        }

        // Exactly one simulation tick. The adapter owns elapsed real time.
        public void Tick(ShooterInput input)
        {
            if (input.Restart)
            {
                Reset();
                return;
            }
            if (GameOver)
                return;

            ElapsedTicks++;
            if (_shotCooldown > 0) _shotCooldown--;
            if (_invulnerability > 0) _invulnerability--;

            float dx = input.MoveX;
            float dy = input.MoveY;
            float length = (float)Math.Sqrt(dx * dx + dy * dy);
            if (length > 0f)
            {
                dx /= length;
                dy /= length;
            }
            PlayerX = Clamp(PlayerX + dx * PlayerSpeed * TickSeconds,
                PlayerRadius, Width - PlayerRadius);
            PlayerY = Clamp(PlayerY + dy * PlayerSpeed * TickSeconds,
                PlayerRadius, Height - PlayerRadius);

            if (input.Shoot && _shotCooldown == 0)
            {
                if (_bulletCount < MaxBullets)
                    _bullets[_bulletCount++] = new Actor(PlayerX, PlayerY - 24f);
                _shotCooldown = ShotIntervalTicks; // A full pool still consumes the attempt.
            }

            _spawnCountdown--;
            if (_spawnCountdown == 0)
            {
                float x = SpawnX[_nextSpawnX];
                _nextSpawnX = (_nextSpawnX + 1) % SpawnX.Length;
                if (_enemyCount < MaxEnemies)
                    _enemies[_enemyCount++] = new Actor(x, -EnemyRadius);
                _spawnCountdown = SpawnIntervalTicks;
            }

            // New actors move in their creation tick, too.
            for (int i = 0; i < _bulletCount; i++)
                _bullets[i].Y += BulletSpeed * TickSeconds;
            for (int i = 0; i < _enemyCount; i++)
                _enemies[i].Y += EnemySpeed * TickSeconds;

            // Mark first. Do not remove from either collection while walking it.
            for (int b = 0; b < _bulletCount; b++)
            {
                if (!_bullets[b].Alive) continue;
                for (int e = 0; e < _enemyCount; e++)
                {
                    if (!_enemies[e].Alive) continue;
                    if (!Overlap(_bullets[b].X, _bullets[b].Y, BulletRadius,
                        _enemies[e].X, _enemies[e].Y, EnemyRadius)) continue;
                    _bullets[b].Alive = false;
                    _enemies[e].Alive = false;
                    Score += 100;
                    break; // One bullet cannot hit a second enemy.
                }
            }

            for (int e = 0; e < _enemyCount; e++)
            {
                if (!_enemies[e].Alive) continue;
                if (!Overlap(PlayerX, PlayerY, PlayerRadius,
                    _enemies[e].X, _enemies[e].Y, EnemyRadius)) continue;
                _enemies[e].Alive = false;
                if (_invulnerability == 0)
                {
                    HP--;
                    _invulnerability = InvulnerabilityTicks;
                    if (HP == 0) GameOver = true;
                }
            }

            for (int b = 0; b < _bulletCount; b++)
                if (_bullets[b].Y + BulletRadius < 0f) _bullets[b].Alive = false;
            for (int e = 0; e < _enemyCount; e++)
                if (_enemies[e].Y - EnemyRadius > Height) _enemies[e].Alive = false;

            Compact(_bullets, ref _bulletCount);
            Compact(_enemies, ref _enemyCount);
        }

        private static bool Overlap(float ax, float ay, float ar, float bx, float by, float br)
        {
            float dx = ax - bx;
            float dy = ay - by;
            float radius = ar + br;
            return dx * dx + dy * dy <= radius * radius;
        }

        private static float Clamp(float value, float min, float max)
        {
            return Math.Max(min, Math.Min(max, value));
        }

        private static void Compact(Actor[] actors, ref int count)
        {
            int write = 0;
            for (int read = 0; read < count; read++)
                if (actors[read].Alive) actors[write++] = actors[read];
            for (int i = write; i < count; i++) actors[i] = default(Actor);
            count = write;
        }
    }
}

MonoBehaviourの全コード ​

UnityのUpdateを入口にして、入力と実時間をModelへ渡します。固定tickをこのクラスで進めるため、同じModelを別のFixedUpdateからも重ねて呼ばないようにします。

OnGUIはHP・スコア等の表示専用です。1フレームに複数回呼ばれる場合があるため、ここからModelのtickを進めたり、ダメージを与えたりしません。

csharp
using UnityEngine;
using UnityEngine.Rendering;
using Sny0.Study.Shooter;
#if ENABLE_INPUT_SYSTEM
using UnityEngine.InputSystem;
#endif

// Unity 6.0 (6000.0), 2D Built-In Render Pipeline demo.
// Attach to one empty GameObject in a new scene; no prefab/image/Physics2D is used.
[DisallowMultipleComponent]
public sealed class ShooterDemo : MonoBehaviour
{
    private const double FixedStep = 1.0 / 60.0;
    private const int MaxTicksPerFrame = 5;
    private const float PixelsPerUnit = 100f;
    private const string Controls = "WASD / Arrows: Move    Space: Fire    R: Restart";

    private ShooterModel _model;
    private double _accumulator;
    private bool _restartPending;
    private GameObject _viewRoot;
    private Camera _camera;
    private Texture2D _circleTexture;
    private Sprite _circleSprite;
    private SpriteRenderer _playerView;
    private SpriteRenderer[] _bulletViews;
    private SpriteRenderer[] _enemyViews;
    private GUIStyle _hudStyle;
    private GUIStyle _helpStyle;
    private GUIStyle _gameOverStyle;
    private GUIStyle _panelStyle;
    private string _hudText = "";
    private int _shownScore = -1;
    private int _shownHP = -1;
    private bool _keyboardAvailable = true;

    private void Awake()
    {
        if (GraphicsSettings.currentRenderPipeline != null)
        {
            Debug.LogError("ShooterDemo targets a 2D Built-In Render Pipeline scene. See README for URP conditions.", this);
            enabled = false;
            return;
        }

        _model = new ShooterModel();
        _viewRoot = new GameObject("ShooterDemo - owned views");
        _viewRoot.transform.SetParent(transform, false);
        CreateCircleSprite();

        GameObject cameraObject = new GameObject("ShooterDemo Camera");
        cameraObject.transform.SetParent(_viewRoot.transform, false);
        cameraObject.transform.position = new Vector3(0f, 0f, -10f);
        _camera = cameraObject.AddComponent<Camera>();
        _camera.orthographic = true;
        _camera.clearFlags = CameraClearFlags.SolidColor;
        _camera.backgroundColor = new Color(0.055f, 0.085f, 0.075f);
        _camera.nearClipPlane = 0.1f;
        _camera.farClipPlane = 50f;
        _camera.depth = 10f; // Leave existing scene cameras alive and unchanged.

        _playerView = CreateView("Player", ShooterModel.PlayerRadius,
            new Color(0.38f, 0.88f, 0.65f), 2);
        _bulletViews = CreatePool("Bullet", ShooterModel.MaxBullets, ShooterModel.BulletRadius,
            new Color(1f, 0.91f, 0.54f), 1);
        _enemyViews = CreatePool("Enemy", ShooterModel.MaxEnemies, ShooterModel.EnemyRadius,
            new Color(0.95f, 0.40f, 0.32f), 0);
        FitCamera();
        SynchronizeViews();
        UpdateHudText();
    }

    private void OnEnable()
    {
        _accumulator = 0.0;
        _restartPending = false;
        if (_viewRoot != null) _viewRoot.SetActive(true);
    }

    private void OnDisable()
    {
        _accumulator = 0.0;
        _restartPending = false;
        if (_viewRoot != null) _viewRoot.SetActive(false);
    }

    private void Update()
    {
        if (_model == null) return;
        ShooterInput frameInput = ReadInput();
        _restartPending |= frameInput.Restart; // Preserve an edge until one tick consumes it.
        _accumulator += System.Math.Min((double)Time.deltaTime, 0.1);

        int ticks = 0;
        while (_accumulator >= FixedStep && ticks < MaxTicksPerFrame)
        {
            ShooterInput tickInput = new ShooterInput(frameInput.MoveX, frameInput.MoveY,
                frameInput.Shoot, _restartPending);
            _restartPending = false;
            _model.Tick(tickInput);
            _accumulator -= FixedStep;
            ticks++;
        }
        if (_accumulator >= FixedStep)
            _accumulator %= FixedStep; // Discard every remaining whole tick, keep the fraction.

        FitCamera();
        SynchronizeViews();
        UpdateHudText();
    }

    private ShooterInput ReadInput()
    {
#if ENABLE_INPUT_SYSTEM
        Keyboard keyboard = Keyboard.current;
        _keyboardAvailable = keyboard != null;
        if (keyboard == null) return new ShooterInput(0f, 0f, false, false);
        float x = (keyboard.rightArrowKey.isPressed || keyboard.dKey.isPressed ? 1f : 0f)
            - (keyboard.leftArrowKey.isPressed || keyboard.aKey.isPressed ? 1f : 0f);
        float y = (keyboard.downArrowKey.isPressed || keyboard.sKey.isPressed ? 1f : 0f)
            - (keyboard.upArrowKey.isPressed || keyboard.wKey.isPressed ? 1f : 0f);
        return new ShooterInput(x, y, keyboard.spaceKey.isPressed, keyboard.rKey.wasPressedThisFrame);
#elif ENABLE_LEGACY_INPUT_MANAGER
        _keyboardAvailable = true;
        float x = (Input.GetKey(KeyCode.RightArrow) || Input.GetKey(KeyCode.D) ? 1f : 0f)
            - (Input.GetKey(KeyCode.LeftArrow) || Input.GetKey(KeyCode.A) ? 1f : 0f);
        float y = (Input.GetKey(KeyCode.DownArrow) || Input.GetKey(KeyCode.S) ? 1f : 0f)
            - (Input.GetKey(KeyCode.UpArrow) || Input.GetKey(KeyCode.W) ? 1f : 0f);
        return new ShooterInput(x, y, Input.GetKey(KeyCode.Space), Input.GetKeyDown(KeyCode.R));
#else
        _keyboardAvailable = false;
        return new ShooterInput(0f, 0f, false, false);
#endif
    }

    private void CreateCircleSprite()
    {
        const int size = 64;
        _circleTexture = new Texture2D(size, size, TextureFormat.RGBA32, false);
        _circleTexture.name = "ShooterDemo Circle Texture";
        _circleTexture.filterMode = FilterMode.Bilinear;
        _circleTexture.wrapMode = TextureWrapMode.Clamp;
        Color32[] pixels = new Color32[size * size];
        for (int y = 0; y < size; y++)
        {
            for (int x = 0; x < size; x++)
            {
                float dx = x + 0.5f - size * 0.5f;
                float dy = y + 0.5f - size * 0.5f;
                byte alpha = (byte)(255f * Mathf.Clamp01(size * 0.5f - 0.5f - Mathf.Sqrt(dx * dx + dy * dy)));
                pixels[y * size + x] = new Color32(255, 255, 255, alpha);
            }
        }
        _circleTexture.SetPixels32(pixels);
        _circleTexture.Apply(false, true);
        // A sprite diameter of one Unity unit; individual views apply their radius scale.
        _circleSprite = Sprite.Create(_circleTexture, new Rect(0, 0, size, size),
            new Vector2(0.5f, 0.5f), size, 0, SpriteMeshType.FullRect);
        _circleSprite.name = "ShooterDemo Shared Circle";
    }

    private SpriteRenderer CreateView(string label, float radius, Color color, int order)
    {
        GameObject actor = new GameObject(label);
        actor.transform.SetParent(_viewRoot.transform, false);
        actor.transform.localScale = Vector3.one * (2f * radius / PixelsPerUnit);
        SpriteRenderer renderer = actor.AddComponent<SpriteRenderer>();
        renderer.sprite = _circleSprite;
        renderer.color = color;
        renderer.sortingOrder = order;
        renderer.enabled = false;
        return renderer;
    }

    private SpriteRenderer[] CreatePool(string label, int count, float radius, Color color, int order)
    {
        SpriteRenderer[] pool = new SpriteRenderer[count];
        for (int i = 0; i < count; i++)
            pool[i] = CreateView(label + " " + i, radius, color, order);
        return pool;
    }

    private static Vector3 PixelToWorld(float x, float y)
    {
        return new Vector3((x - ShooterModel.Width * 0.5f) / PixelsPerUnit,
            (ShooterModel.Height * 0.5f - y) / PixelsPerUnit, 0f);
    }

    private void FitCamera()
    {
        float aspect = Screen.width / (float)Mathf.Max(1, Screen.height);
        _camera.orthographicSize = Mathf.Max(ShooterModel.Height * 0.5f,
            ShooterModel.Width * 0.5f / aspect) / PixelsPerUnit;
    }

    private void SynchronizeViews()
    {
        _playerView.enabled = true;
        _playerView.transform.position = PixelToWorld(_model.PlayerX, _model.PlayerY);
        _playerView.color = _model.Invulnerable
            ? new Color(0.76f, 1f, 0.89f) : new Color(0.38f, 0.88f, 0.65f);
        for (int i = 0; i < _bulletViews.Length; i++)
        {
            _bulletViews[i].enabled = i < _model.BulletCount;
            if (i < _model.BulletCount)
            {
                ShooterActor bullet = _model.GetBullet(i);
                _bulletViews[i].transform.position = PixelToWorld(bullet.X, bullet.Y);
            }
        }
        for (int i = 0; i < _enemyViews.Length; i++)
        {
            _enemyViews[i].enabled = i < _model.EnemyCount;
            if (i < _model.EnemyCount)
            {
                ShooterActor enemy = _model.GetEnemy(i);
                _enemyViews[i].transform.position = PixelToWorld(enemy.X, enemy.Y);
            }
        }
    }

    private void UpdateHudText()
    {
        if (_shownScore == _model.Score && _shownHP == _model.HP) return;
        _shownScore = _model.Score;
        _shownHP = _model.HP;
        _hudText = "Score: " + _shownScore + "    HP: " + _shownHP;
    }

    private void OnGUI()
    {
        if (_model == null) return;
        // GUI.skin is read only in OnGUI; styles are created once, not per event.
        if (_hudStyle == null)
        {
            _hudStyle = new GUIStyle(GUI.skin.label) { fontSize = 22 };
            _hudStyle.normal.textColor = Color.white;
            _helpStyle = new GUIStyle(_hudStyle) { fontSize = 16 };
            _gameOverStyle = new GUIStyle(_hudStyle)
                { fontSize = 38, alignment = TextAnchor.MiddleCenter };
            _panelStyle = new GUIStyle(GUI.skin.box);
        }
        float scale = Mathf.Min(Screen.width / ShooterModel.Width, Screen.height / ShooterModel.Height);
        if (scale <= 0f) return;
        float x = (Screen.width - ShooterModel.Width * scale) * 0.5f;
        float y = (Screen.height - ShooterModel.Height * scale) * 0.5f;
        Matrix4x4 previous = GUI.matrix;
        try
        {
            GUI.matrix = Matrix4x4.TRS(new Vector3(x, y, 0f), Quaternion.identity,
                new Vector3(scale, scale, 1f));
            GUI.Label(new Rect(12, 8, 600, 32), _hudText, _hudStyle);
            GUI.Label(new Rect(12, 690, 620, 25), Controls, _helpStyle);
            if (!_keyboardAvailable)
                GUI.Label(new Rect(12, 40, 620, 28), "Keyboard unavailable. Check Active Input Handling and Game view focus.", _helpStyle);
            if (_model.GameOver)
            {
                GUI.Box(new Rect(100, 275, 440, 140), GUIContent.none, _panelStyle);
                GUI.Label(new Rect(100, 285, 440, 64), "GAME OVER", _gameOverStyle);
                GUI.Label(new Rect(220, 365, 260, 30), "Press R to restart", _helpStyle);
            }
        }
        finally
        {
            GUI.matrix = previous;
        }
    }

    private void OnDestroy()
    {
        // Only resources created here are destroyed. Existing cameras/materials are not owned.
        if (_viewRoot != null) Destroy(_viewRoot);
        if (_circleSprite != null) Destroy(_circleSprite);
        if (_circleTexture != null) Destroy(_circleTexture);
    }
}

座標と表示の読み方 ​

Modelの(0, 0)は画面左上です。Unity側では画面中心を原点に置き、100pxを1unitとして次の変換を使います。

xUnity=(xModel−320)/100,yUnity=(360−yModel)/100

例えばModelの自機初期位置(320, 650)は、Unityでは(0, -2.9)になります。円の直径も同じ比率でスケールします。この関係がずれると、見た目の大きさ・位置とModelの当たり判定が一致しなくなります。

表示用GameObjectの一覧はModelの値を描くためのものです。表示側のSetActive(false)でゲームの敵を倒すのではなく、Modelの有効な要素を読み、余った表示枠を無効にします。

Physics2Dを使う版へ変えるなら ​

このサンプルはUnityの物理エンジンを使わず、共通Model内で位置と円の衝突を計算します。Rigidbody2Dを後付けしてTransformもModelも位置を変更すると、どちらの結果を採用するかが曖昧になります。

Unityの物理を採用する場合は、物理側へ位置・衝突を任せ、イベントからゲームのルールを更新する設計へ変えます。FixedUpdateという名前のメソッドへ移すだけで、今のModelと物理側の状態が自動的に同期するわけではありません。

確認範囲 ​

2026-10-30時点で、次を確認しました。

確認対象結果
純C# Model検証用.NET環境のReleaseビルドと36項目の実行検査が成功
Unity Editorでのコンパイル6000.3.27f1の新規Built-Inプロジェクトで、両ファイルを旧Input Manager側の条件で実コンパイルし、Modelの簡易実行検査が成功
API資料6000.0系とInput System 1.11系の公式資料を参照
画面の描画、実キー入力、Player build未確認
