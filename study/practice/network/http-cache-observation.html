C++とC#でETag・304・保存本文の再利用を観察する ​

同じPCのHTTPサーバーへ4回GETし、ETagで再検証します。304を受け取ったとき、受信本文は0バイトでも、クライアントが保存していた10バイトを使えることを比べます。仕組みと図はHTTPキャッシュと再検証を参照してください。

これは実際のHTTP条件付き要求と、自前のメモリ内キャッシュを組み合わせた教材です。ブラウザの自動キャッシュの挙動や、一般的なHTTPキャッシュの完全実装を検証する例ではありません。

入手してローカルで実行する ​

共通サーバー2ファイルと、使う言語の3ファイルを保存します。両言語を試す場合は計8ファイルです。

サーバーを起動する ​

Node.jsを使い、共通フォルダで起動します。外部パッケージは不要です。

powershell
node .\server.cjs

サーバーは127.0.0.1:0にだけbindし、OSが割り当てたport=とURLを表示します。固定portや外部hostは指定しません。.cjsはCommonJSを明示するため、親package.jsonのmodule設定によらず配布実体を実行できます。Node公式：Packages

サーバーのターミナルを開いたまま、表示されたportを別ターミナルのクライアントへ渡します。終了するときはCtrl+C、またはサーバーへstopと入力します。受付を閉じ、残存接続は後片付け期限後に切断します。Node公式：HTTP server

同じ本文で4回のGETを比べる ​

/resourceの本文はUTF-8のCache あ\n、次の10バイトです。クライアントは独立した期待バイト列と照合します。

text
43 61 63 68 65 20 E3 81 82 0A

サーバーはETag "study-v1"とCache-Control: no-cacheを返します。no-cacheは保存禁止ではなく、保存応答を後で使う前に再検証を要求する指定です。このコードは本文とETagを変数へ保存します。RFC 9111 §5.2.2.4：no-cache

回If-None-Match応答クライアントが使う本文
1送らない200、本文10バイト受信本文とETagを保存
2保存した"study-v1"304、本文0バイト保存していた本文10バイトを再利用
3"other,tag", W/"study-v1"304、本文0バイト同じ保存本文を再利用
4"study-old"200、本文10バイト受信本文を使う

2・3回目のvalidatorは、1回目に受け取ったETagを変数から組み立てます。304に本文を足したり、HTTPライブラリが自動的に200へ変換した結果を期待したりする構成ではありません。受信本文0バイトと、利用する保存本文10バイトを別々に検査・出力します。

3回目はlist内に弱いtagを含みます。If-None-Matchは弱い比較を使うため、このケースではW/"study-v1"と"study-v1"が一致します。また"other,tag"のcommaは引用符内のtagデータで、listの区切りではありません。RFC 9110 §13.1.2：If-None-Match

4回目は意図的に不一致のvalidatorを送る例です。サーバーの本文やETagを更新した再現ではありません。このサーバーでは4回を通して同じ本文・ETagを返します。

サーバーの限定仕様 ​

GETとHEADだけを受け付けます。200ではContent-Lengthを正しい本文長10にし、HEADではその長さを示した上で本文を送りません。304では本文とContent-Lengthを省略し、ETag・Cache-Control・現在のDateを返します。HTTP一般で304のContent-Lengthが常に禁止されるという意味ではなく、この教材の応答方針です。RFC 9110 §15.4.5：304、§8.6：Content-Length

If-None-Matchは単独*、または最大16個のentity-tagを文字単位で解析し、弱い比較を行います。OWSと引用符内のcommaを扱い、値は1024文字、HTTPヘッダー全体は4096バイトに制限します。空のlist要素や末尾commaは拒否する限定subsetです。要求本文、If-Match/日時validator、Range、Vary、Age、freshness計算等まで扱う完全なサーバー・キャッシュではありません。

API・所有権・処理上限 ​

C++は同期WinHTTPで、HINTERNETをRAIIで閉じます。WinHTTPはユーザーのブラウザキャッシュと共有する仕組みではありません。ここでの保存・再利用はクライアント自身の変数で行います。Microsoft：About WinHTTP

各phaseのtimeoutは最大8秒、単調時計による全体予算は30秒です。API呼出しの前後に予算を確認しますが、進行中の同期APIをその瞬間に必ず中断する厳密な実時間の終了保証ではありません。Microsoft：WinHttpSetTimeouts

C#はHttpClientでHTTP/1.1を指定し、ResponseHeadersRead後の本文読取りにも、4回を通して同じ30秒のCancellationTokenを渡します。ConnectTimeoutは8秒です。usingで要求・応答・stream・client等を解放します。こちらもブラウザの自動キャッシュを試す処理ではありません。Microsoft：SendAsync、UseProxy

両クライアントは各本文4KiBを上限にし、実際の読取り数を累積します。API失敗・取消し・検査不一致は終了1、引数不正は2です。Dateや割当port、処理時間を固定値として照合しません。サーバー側もheaders timeout 5秒、request/socket timeout 8秒を設け、停止時は新規受付を閉じて残存接続を片付けます。

js
"use strict";

// Explicit CommonJS extension works independently of a parent package.json.

const http = require("node:http");
const readline = require("node:readline");

if (process.argv.length !== 2) {
  console.error("error=invalid_arguments expected=no_arguments");
  process.exitCode = 2;
} else {
  const body = Buffer.from("Cache \u3042\n", "utf8");
  const expected = Buffer.from([0x43, 0x61, 0x63, 0x68, 0x65, 0x20, 0xe3, 0x81, 0x82, 0x0a]);
  if (!body.equals(expected)) { throw new Error("fixture-encoding-mismatch"); }
  const etag = '"study-v1"';
  let requests = 0;
  let stopping = false;
  let forceCloseTimer = null;

  // Limited field parser: wildcard or 1..16 tags, with no empty list members.
  // A comma inside quotes is opaque tag data, not a list separator.
  function parseIfNoneMatch(value) {
    if (typeof value !== "string" || value.length > 1024) { return null; }
    let index = 0;
    const tags = [];
    const skipOws = () => {
      while (value[index] === " " || value[index] === "\t") { index += 1; }
    };
    skipOws();
    if (value[index] === "*") {
      index += 1;
      skipOws();
      return index === value.length ? { wildcard: true, tags } : null;
    }
    while (index < value.length) {
      if (tags.length === 16) { return null; }
      if (value.slice(index, index + 2) === "W/") { index += 2; }
      if (value[index] !== '"') { return null; }
      index += 1;
      const start = index;
      while (index < value.length && value[index] !== '"') {
        const code = value.charCodeAt(index);
        if (!(code === 0x21 || (code >= 0x23 && code <= 0x7e) || (code >= 0x80 && code <= 0xff))) { return null; }
        index += 1;
      }
      if (value[index] !== '"') { return null; }
      tags.push(value.slice(start, index));
      index += 1;
      skipOws();
      if (index === value.length) { return { wildcard: false, tags }; }
      if (value[index] !== ",") { return null; }
      index += 1;
      skipOws();
      if (index === value.length) { return null; }
    }
    return null;
  }

  const server = http.createServer({ maxHeaderSize: 4096, requestTimeout: 8000, headersTimeout: 5000 }, (request, response) => {
    requests += 1;
    const number = requests;
    const finishEmpty = (status, condition) => {
      response.statusCode = status;
      response.setHeader("Content-Length", "0");
      response.setHeader("Connection", "close");
      response.end();
      console.log(`request=${number} method=${request.method} status=${status} condition=${condition}`);
    };
    if (request.method !== "GET" && request.method !== "HEAD") {
      response.setHeader("Allow", "GET, HEAD");
      finishEmpty(405, "unsupported_method");
      return;
    }
    if (request.url !== "/resource") {
      finishEmpty(404, "unknown_resource");
      return;
    }
    // Request bodies are outside this fixed GET/HEAD teaching protocol.
    if (request.headers["transfer-encoding"] !== undefined ||
        (request.headers["content-length"] !== undefined && request.headers["content-length"] !== "0")) {
      finishEmpty(400, "request_body_not_supported");
      return;
    }
    const raw = request.headers["if-none-match"];
    const condition = raw === undefined ? undefined : parseIfNoneMatch(raw);
    if (condition === null) {
      finishEmpty(400, "unsupported_or_invalid_validator");
      return;
    }
    // If-None-Match on GET/HEAD uses weak comparison: compare opaque tags.
    const matched = condition !== undefined && (condition.wildcard || condition.tags.includes("study-v1"));
    response.statusCode = matched ? 304 : 200;
    response.setHeader("Date", new Date().toUTCString());
    response.setHeader("ETag", etag);
    response.setHeader("Cache-Control", "no-cache");
    if (matched) {
      // No Content-Length and no message body in this 304 response.
      response.end();
    } else {
      response.setHeader("Content-Type", "text/plain; charset=utf-8");
      response.setHeader("Content-Length", String(body.length));
      response.end(request.method === "HEAD" ? undefined : body);
    }
    console.log(`request=${number} method=${request.method} status=${response.statusCode} condition=${raw === undefined ? "absent" : matched ? "matched" : "not_matched"}`);
  });
  server.keepAliveTimeout = 1000;
  server.setTimeout(8000, (socket) => socket.destroy());
  server.on("clientError", (_error, socket) => {
    if (socket.writable) {
      socket.end(`HTTP/1.1 400 Bad Request\r\nDate: ${new Date().toUTCString()}\r\nContent-Length: 0\r\nConnection: close\r\n\r\n`);
    } else { socket.destroy(); }
  });
  const input = readline.createInterface({ input: process.stdin, terminal: false });
  function stop() {
    if (stopping) { return; }
    stopping = true;
    console.log("server_stopping=true");
    server.close(() => {
      clearTimeout(forceCloseTimer);
      input.close();
      process.stdin.pause();
      console.log("server_closed=true");
    });
    // Bound cleanup of an incomplete local request after listener shutdown.
    forceCloseTimer = setTimeout(() => server.closeAllConnections(), 1000);
    forceCloseTimer.unref();
  }
  input.on("line", (line) => { if (line.trim() === "stop") { stop(); } });
  process.on("SIGINT", stop);
  process.on("SIGTERM", stop);
  server.once("error", (error) => {
    console.error(`server_error=${error.code || "unknown"}`);
    input.close();
    process.stdin.pause();
    process.exitCode = 1;
  });
  server.listen(0, "127.0.0.1", () => {
    const address = server.address();
    console.log(`port=${address.port}`);
    console.log(`url=http://127.0.0.1:${address.port}/resource`);
    console.log("stop=Ctrl+C_or_stdin_line_stop");
  });
}

namespace {
constexpr std::size_t BodyLimit = 4096;
constexpr std::array<BYTE, 10> Expected = {0x43, 0x61, 0x63, 0x68, 0x65, 0x20, 0xe3, 0x81, 0x82, 0x0a};

class ApiError final : public std::runtime_error {
public:
    ApiError(const char* operation, DWORD value) : std::runtime_error(operation), code(value) {}
    DWORD code;
};

void Require(BOOL ok, const char* operation) {
    if (!ok) { throw ApiError(operation, GetLastError()); }
}
void Expect(bool ok, const char* reason) { if (!ok) { throw std::runtime_error(reason); } }

class InternetHandle final {
public:
    InternetHandle(HINTERNET value, const char* operation) : value_(value) {
        if (!value_) { throw ApiError(operation, GetLastError()); }
    }
    ~InternetHandle() { if (value_) { WinHttpCloseHandle(value_); } }
    InternetHandle(const InternetHandle&) = delete;
    InternetHandle& operator=(const InternetHandle&) = delete;
    HINTERNET get() const noexcept { return value_; }
private:
    HINTERNET value_;
};

class Budget final {
public:
    Budget() : end_(Clock::now() + std::chrono::seconds(30)) {}
    void Check() const { Expect(Clock::now() < end_, "overall_budget_expired"); }
    void Apply(HINTERNET handle) const {
        Check();
        const auto remaining = std::chrono::duration_cast<std::chrono::milliseconds>(end_ - Clock::now()).count();
        const int timeout = static_cast<int>(std::clamp(remaining, 1LL, 8000LL));
        Require(WinHttpSetTimeouts(handle, timeout, timeout, timeout, timeout), "WinHttpSetTimeouts");
    }
private:
    using Clock = std::chrono::steady_clock;
    Clock::time_point end_;
};

std::optional<INTERNET_PORT> ParsePort(std::string_view input) {
    if (input.empty() || input.size() > 5) { return std::nullopt; }
    unsigned int value = 0;
    for (char digit : input) {
        if (digit < '0' || digit > '9') { return std::nullopt; }
        value = value * 10U + static_cast<unsigned int>(digit - '0');
    }
    if (value == 0 || value > 65535U) { return std::nullopt; }
    return static_cast<INTERNET_PORT>(value);
}

std::optional<std::wstring> Header(HINTERNET request, const wchar_t* name) {
    std::array<wchar_t, 1025> buffer{};
    DWORD size = static_cast<DWORD>(sizeof(buffer));
    if (!WinHttpQueryHeaders(request, WINHTTP_QUERY_CUSTOM, name, buffer.data(), &size, WINHTTP_NO_HEADER_INDEX)) {
        const DWORD error = GetLastError();
        if (error == ERROR_WINHTTP_HEADER_NOT_FOUND) { return std::nullopt; }
        throw ApiError("WinHttpQueryHeaders", error);
    }
    return std::wstring(buffer.data());
}

std::string Ascii(std::wstring_view value) {
    std::string output;
    output.reserve(value.size());
    for (wchar_t character : value) {
        Expect(character >= 0x20 && character <= 0x7e, "unexpected_non_ascii_header");
        output.push_back(static_cast<char>(character));
    }
    return output;
}

struct Response {
    DWORD status = 0;
    std::wstring etag;
    std::vector<BYTE> body;
};

Response Get(HINTERNET connection, const Budget& budget, std::wstring_view validator) {
    InternetHandle request(WinHttpOpenRequest(connection, L"GET", L"/resource", L"HTTP/1.1",
        WINHTTP_NO_REFERER, WINHTTP_DEFAULT_ACCEPT_TYPES, 0), "WinHttpOpenRequest");
    DWORD disabled = WINHTTP_DISABLE_REDIRECTS | WINHTTP_DISABLE_AUTHENTICATION | WINHTTP_DISABLE_COOKIES;
    Require(WinHttpSetOption(request.get(), WINHTTP_OPTION_DISABLE_FEATURE, &disabled, sizeof(disabled)), "disable_features");
    const std::wstring headers = validator.empty() ? L"" : L"If-None-Match: " + std::wstring(validator) + L"\r\n";
    budget.Apply(request.get());
    Require(WinHttpSendRequest(request.get(), headers.empty() ? WINHTTP_NO_ADDITIONAL_HEADERS : headers.c_str(),
        static_cast<DWORD>(headers.size()), WINHTTP_NO_REQUEST_DATA, 0, 0, 0), "WinHttpSendRequest");
    budget.Check();
    budget.Apply(request.get());
    Require(WinHttpReceiveResponse(request.get(), nullptr), "WinHttpReceiveResponse");
    budget.Check();
    Response result;
    DWORD size = sizeof(result.status);
    Require(WinHttpQueryHeaders(request.get(), WINHTTP_QUERY_STATUS_CODE | WINHTTP_QUERY_FLAG_NUMBER,
        WINHTTP_HEADER_NAME_BY_INDEX, &result.status, &size, WINHTTP_NO_HEADER_INDEX), "query_status");
    const auto etag = Header(request.get(), L"ETag");
    Expect(etag.has_value(), "missing_etag");
    result.etag = *etag;
    Expect(Header(request.get(), L"Cache-Control") == std::optional<std::wstring>(L"no-cache"), "cache_control_mismatch");
    const auto date = Header(request.get(), L"Date");
    Expect(date.has_value() && !date->empty(), "missing_date");
    const auto length = Header(request.get(), L"Content-Length");
    if (result.status == 200) { Expect(length == std::optional<std::wstring>(L"10"), "content_length_mismatch"); }
    if (result.status == 304) { Expect(!length.has_value(), "unexpected_304_content_length"); }
    std::array<BYTE, 512> buffer{};
    for (;;) {
        budget.Apply(request.get());
        const DWORD requested = static_cast<DWORD>(std::min(buffer.size(), BodyLimit - result.body.size() + 1U));
        DWORD received = 0;
        Require(WinHttpReadData(request.get(), buffer.data(), requested, &received), "WinHttpReadData");
        budget.Check();
        Expect(received <= requested && received <= BodyLimit - result.body.size(), "body_limit_or_count_invalid");
        result.body.insert(result.body.end(), buffer.begin(), buffer.begin() + static_cast<std::ptrdiff_t>(received));
        if (received == 0) { break; }
    }
    return result;
}

bool ExpectedBody(const std::vector<BYTE>& body) {
    return body.size() == Expected.size() && std::equal(body.begin(), body.end(), Expected.begin());
}

void Observe(int step, const Response& response, DWORD status, bool reuse, const std::vector<BYTE>& effective) {
    Expect(response.status == status, "unexpected_http_status");
    Expect(response.etag == L"\"study-v1\"", "unexpected_etag");
    Expect(status == 304 ? response.body.empty() : ExpectedBody(response.body), "wire_body_mismatch");
    Expect(ExpectedBody(effective), "effective_cached_body_mismatch");
    std::cout << "step=" << step << " status=" << response.status
              << " received_body_bytes=" << response.body.size() << " etag=" << Ascii(response.etag)
              << " reuse_saved_body=" << (reuse ? "true" : "false")
              << " effective_body_bytes=" << effective.size() << '\n';
}

void Run(INTERNET_PORT port) {
    const Budget budget;
    InternetHandle session(WinHttpOpen(L"Sny0StudyHttpCache/1.0", WINHTTP_ACCESS_TYPE_NO_PROXY,
        WINHTTP_NO_PROXY_NAME, WINHTTP_NO_PROXY_BYPASS, 0), "WinHttpOpen");
    DWORD protocols = 0;
    Require(WinHttpSetOption(session.get(), WINHTTP_OPTION_ENABLE_HTTP_PROTOCOL, &protocols, sizeof(protocols)), "http_protocol_policy");
    budget.Apply(session.get());
    InternetHandle connection(WinHttpConnect(session.get(), L"127.0.0.1", port, 0), "WinHttpConnect");
    std::cout << "target=http://127.0.0.1:" << port << "/resource cache_model=explicit_client_memory\n";
    const Response first = Get(connection.get(), budget, L"");

    const std::wstring cachedEtag = first.etag;
    Observe(1, first, 200, false, cachedBody);
    const Response second = Get(connection.get(), budget, cachedEtag);
    Observe(2, second, 304, true, cachedBody);
    const Response third = Get(connection.get(), budget, L"\"other,tag\", W/" + cachedEtag);
    Observe(3, third, 304, true, cachedBody);
    const Response fourth = Get(connection.get(), budget, L"\"study-old\"");
    cachedBody = fourth.body;
    Observe(4, fourth, 200, false, cachedBody);
    std::cout << "observations=4 result=passed\n";
}

using System;
using System.Globalization;
using System.IO;
using System.Linq;
using System.Net;
using System.Net.Http;
using System.Threading;
using System.Threading.Tasks;

internal static class Program
{
    private const int BodyLimit = 4096;
    private static readonly byte[] Expected =
        { 0x43, 0x61, 0x63, 0x68, 0x65, 0x20, 0xe3, 0x81, 0x82, 0x0a };

    private sealed record Response(HttpStatusCode Status, string ETag, byte[] Body);

    private static void Expect(bool condition, string reason)
    {
        if (!condition) { throw new InvalidOperationException(reason); }
    }

    private static bool TryPort(string[] args, out int port)
    {
        port = 0;
        if (args.Length != 1 || args[0].Length == 0 || args[0].Length > 5) { return false; }
        foreach (char digit in args[0])
        {
            if (digit < '0' || digit > '9') { return false; }
            port = port * 10 + digit - '0';
        }
        return port >= 1 && port <= 65535;
    }

    private static async Task<Response> GetAsync(HttpClient client, Uri target,
                                                 string? validator, CancellationToken token)
    {
        using HttpRequestMessage request = new(HttpMethod.Get, target)
        {
            Version = HttpVersion.Version11,
            VersionPolicy = HttpVersionPolicy.RequestVersionExact
        };
        if (validator is not null)
        {
            Expect(request.Headers.TryAddWithoutValidation("If-None-Match", validator), "cannot_set_validator");
        }
        using HttpResponseMessage response = await client.SendAsync(request,
            HttpCompletionOption.ResponseHeadersRead, token).ConfigureAwait(false);
        Expect(response.Version == HttpVersion.Version11, "unexpected_http_version");
        string etag = response.Headers.ETag?.ToString() ?? throw new InvalidOperationException("missing_etag");
        Expect(response.Headers.CacheControl?.ToString() == "no-cache", "cache_control_mismatch");
        Expect(response.Headers.Date.HasValue, "missing_date");
        bool hasLength = response.Content.Headers.NonValidated.TryGetValues("Content-Length", out var lengths);
        if (response.StatusCode == HttpStatusCode.OK)
        {
            Expect(hasLength && lengths.ToString() == "10", "content_length_mismatch");
        }
        if (response.StatusCode == HttpStatusCode.NotModified)
        {
            Expect(!hasLength, "unexpected_304_content_length");
        }
        using Stream stream = await response.Content.ReadAsStreamAsync(token).ConfigureAwait(false);
        using MemoryStream bytes = new();
        byte[] buffer = new byte[512];
        int total = 0;
        while (true)
        {
            int requested = Math.Min(buffer.Length, BodyLimit - total + 1);
            int received = await stream.ReadAsync(buffer.AsMemory(0, requested), token).ConfigureAwait(false);
            Expect(received >= 0 && received <= requested && received <= BodyLimit - total, "body_limit_or_count_invalid");
            bytes.Write(buffer, 0, received);
            total += received;
            if (received == 0) { break; }
        }
        return new Response(response.StatusCode, etag, bytes.ToArray());
    }

    private static void Observe(int step, Response response, HttpStatusCode status,
                                bool reuse, byte[] effective)
    {
        Expect(response.Status == status, "unexpected_http_status");
        Expect(response.ETag == "\"study-v1\"", "unexpected_etag");
        Expect(status == HttpStatusCode.NotModified ? response.Body.Length == 0 : response.Body.SequenceEqual(Expected), "wire_body_mismatch");
        Expect(effective.SequenceEqual(Expected), "effective_cached_body_mismatch");
        Console.WriteLine($"step={step} status={(int)response.Status} received_body_bytes={response.Body.Length} " +
                          $"etag={response.ETag} reuse_saved_body={reuse.ToString().ToLowerInvariant()} " +
                          $"effective_body_bytes={effective.Length}");
    }

    private static async Task RunAsync(int port)
    {
        using SocketsHttpHandler handler = new()
        {
            UseProxy = false,
            AllowAutoRedirect = false,
            UseCookies = false,
            AutomaticDecompression = DecompressionMethods.None,
            Credentials = null,
            DefaultProxyCredentials = null,
            ConnectTimeout = TimeSpan.FromSeconds(8)
        };
        using HttpClient client = new(handler, disposeHandler: false)
        {
            Timeout = Timeout.InfiniteTimeSpan
        };
        // One cancellation budget covers all four SendAsync and body-read phases.
        using CancellationTokenSource budget = new(TimeSpan.FromSeconds(30));
        Uri target = new($"http://127.0.0.1:{port.ToString(CultureInfo.InvariantCulture)}/resource");
        Console.WriteLine($"target={target} cache_model=explicit_client_memory");
        Response first = await GetAsync(client, target, null, budget.Token).ConfigureAwait(false);
        byte[] cachedBody = first.Body;
        string cachedETag = first.ETag;
        Observe(1, first, HttpStatusCode.OK, false, cachedBody);
        Response second = await GetAsync(client, target, cachedETag, budget.Token).ConfigureAwait(false);
        Observe(2, second, HttpStatusCode.NotModified, true, cachedBody);
        Response third = await GetAsync(client, target, "\"other,tag\", W/" + cachedETag, budget.Token).ConfigureAwait(false);
        Observe(3, third, HttpStatusCode.NotModified, true, cachedBody);
        Response fourth = await GetAsync(client, target, "\"study-old\"", budget.Token).ConfigureAwait(false);
        cachedBody = fourth.Body;
        Observe(4, fourth, HttpStatusCode.OK, false, cachedBody);
        Console.WriteLine("observations=4 result=passed");
    }

    private static async Task<int> Main(string[] args)
    {
        if (!TryPort(args, out int port))
        {
            Console.Error.WriteLine("usage: HttpCacheObservation <port_1_to_65535>");
            return 2;
        }
        try
        {
            await RunAsync(port).ConfigureAwait(false);
            Console.WriteLine("caller_scope=finished");
            return 0;
        }
        catch (OperationCanceledException)
        {
            Console.Error.WriteLine("api_status=cancelled budget_seconds=30");
        }
        catch (HttpRequestException error)
        {
            Console.Error.WriteLine($"api_status=failed request_error={error.HttpRequestError} hresult=0x{error.HResult:X8}");
        }
        catch (Exception error)
        {
            Console.Error.WriteLine($"observation_status=failed exception={error.GetType().Name} reason={error.Message}");
        }
        return 1;
    }
}
