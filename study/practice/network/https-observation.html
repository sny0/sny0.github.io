C++とC#でHTTPSの応答とTLS情報を観察する ​

固定URL https://example.com/へGETし、HTTP応答と、APIが公開する接続のTLS情報を分けて調べます。C++はWindowsのWinHTTP、C#は.NET 10のHttpClientを使います。TLS内部の仕組みと図はTLSとHTTPS、暗号化前のメッセージ構造はHTTPを参照してください。

--liveを指定した場合だけ通信します。引数なしは対象と使い方を表示して終了し、GETを実行しません。外部サービスが必要なので、未通信の表示をHTTPSの検証成功として数えません。IANAのexample.comは文書用のドメインですが、Webサービスはベストエフォートです。常時稼働や内容の固定を前提にしません。IANA：Example Domains

何を観察するか ​

出力分かること分からないこと
response_headersとhttp_statusHTTP応答ヘッダーが得られたことと状態コードアプリケーション上の処理の正しさ
protocol・cipher_suiteAPIが公開する接続のTLS版と暗号スイートhandshake各パケットや暗号処理の全内部
peer_certificate_sha256相手の公開証明書のSHA-256フィンガープリント秘密鍵、将来も同じ証明書である保証
response_complete・body_bytes上限内でHTTP本文を最後まで読めたことTLS close_notifyやTCP EOFのwire上の確認

通常のホスト名・証明書チェーン検証を保ち、検証失敗を無視するsecurity flagや、常に許可するcallbackは使いません。フィンガープリントは観察用で、コード中の固定値との照合や独自の認証判断には使いません。TLS版もOSの既定に任せます。

失効確認は別の条件です。C#のCertificateRevocationCheckModeは既定のNoCheckを表示し、C++も失効確認を明示的に有効化する設定を追加していません。「最新のすべての失効情報を照会した」という実験ではありません。Microsoft：CertificateRevocationCheckMode、WinHTTPのオプション

入手して実行する ​

各言語の3ファイルを、それぞれ同じフォルダへ保存します。ソースと出力はASCIIです。ユーザー名・パスワード等は入力せず、任意の接続先を指定する機能もありません。redirectは追跡せず、認証情報やCookieの自動送信を無効にしています。OS既定のproxyを利用し得ますが、設定は変更しません。

HTTP 200、TLS 1.3、暗号スイート、本文577バイト、読取り2回などは今回の観測値です。IP、公開証明書、本文、読取り回数、filterの呼出し回数、時間を固定assertしません。APIを1回呼んだことから、内部の接続試行・TLS handshake・wire上の要求も必ず1回だったとは推定しません。WinHTTPとHttpClientではproxyやキャッシュ等の内部方針も一致するとは限りません。

完了・上限・所有権を読む ​

C++は同期WinHTTPです。WinHttpSendRequest、WinHttpReceiveResponse、WinHttpReadDataの帰還を確認して次へ進みます。各phaseのtimeoutは最大8秒、単調時計で管理する全体予算は30秒です。残り予算をAPI呼出しの前後で確認しますが、進行中の同期呼出しをその瞬間に中断する仕組みではなく、厳密な実時間の終了保証ではありません。Microsoft：WinHttpSetTimeouts

WINHTTP_OPTION_SECURITY_INFOはSChannelの接続情報を取得します。新しいWindowsへの依存があり、取得できない場合はエラー番号と観測不可を表示してHTTP本文の処理を続けます。検証を回避して継続する意味ではありません。相手証明書の複製contextはRAIIでCertFreeCertificateContextし、要求・接続・sessionも逆順に閉じます。Microsoft：WINHTTP_SECURITY_INFO、SERVER_CERT_CONTEXT

C#はResponseHeadersReadでヘッダーを受け取り、その後のReadAsStreamAsyncとReadAsyncにも同じ30秒のCancellationTokenを渡します。ヘッダー受信完了は本文受信完了ではありません。取消要求もOS内部の全処理停止や厳密な終了時刻の保証ではなく、awaitの結果または例外を回収してから所有物をDisposeします。Microsoft：SendAsync

PlaintextStreamFilterでは、得られたstreamがSslStreamの場合に認証済みの接続情報を読み、元のstreamを返します。stream自体をread・交換・Disposeしません。一方、RemoteCertificateを取得した側には返却証明書のDispose責任があります。重複参照を除いて保持し、HTTP client/handlerの利用終了後に解放します。保持先の終了状態も同じlockで確認し、終了後に遅れてきたcallbackが証明書を追加しないようにします。caller_scope=finishedはこの利用者側スコープの終了で、OS資源やGC対象がすべてゼロになったという計測ではありません。Microsoft：PlaintextStreamFilter、RemoteCertificateの所有権

両方とも実際の読取り数を累積し、64KiBを超える本文を拒否します。上限ちょうどの場合も追加の1バイトを読める要求で超過を検出します。readの0はAPIが表すHTTP本文の完了です。TLS close_notify、TCP FIN、物理パケットの受信を直接観測した値ではありません。API失敗・取消し・上限超過を成功へ置き換えず終了1にし、HTTP非2xxも状態を記録した上で終了1にします。

今回は通常経路の実行確認です。期限切れ、証明書の期限・名前・チェーン不正、本文上限超過、非2xx、proxy認証、通信断の故意注入はしていません。他OS・他コンパイラ/runtime・Unityも未実行です。TLS内部はAPIへ委ねており、wireの暗号化データやhandshake全体、秘密鍵を取得するサンプルではありません。

#define NOMINMAX

#include <iostream>
#include <stdexcept>
#include <string>
#include <string_view>

namespace {
constexpr std::size_t BodyLimit = 64U * 1024U;

class ApiError final : public std::runtime_error {
public:
    ApiError(const char* operation, DWORD value)
        : std::runtime_error(operation), code(value) {}
    DWORD code;
};

void Require(BOOL ok, const char* operation) {
    if (!ok) { throw ApiError(operation, GetLastError()); }
}

class InternetHandle final {
public:
    InternetHandle(HINTERNET value, const char* operation) : value_(value) {
        if (!value_) { throw ApiError(operation, GetLastError()); }
    }
    ~InternetHandle() { if (value_) { WinHttpCloseHandle(value_); } }
    InternetHandle(const InternetHandle&) = delete;
    InternetHandle& operator=(const InternetHandle&) = delete;
    HINTERNET get() const noexcept { return value_; }
private:
    HINTERNET value_;
};

class Certificate final {
public:
    explicit Certificate(HINTERNET request) {
        DWORD size = sizeof(value_);
        Require(WinHttpQueryOption(request, WINHTTP_OPTION_SERVER_CERT_CONTEXT,
                                   &value_, &size), "server_certificate");
        if (!value_) { throw std::runtime_error("null_server_certificate"); }
    }
    ~Certificate() { if (value_) { CertFreeCertificateContext(value_); } }
    Certificate(const Certificate&) = delete;
    Certificate& operator=(const Certificate&) = delete;
    PCCERT_CONTEXT get() const noexcept { return value_; }
private:
    PCCERT_CONTEXT value_ = nullptr;
};

class Budget final {
public:
    Budget() : start_(Clock::now()), end_(start_ + std::chrono::seconds(30)) {}
    void Check() const {
        if (Clock::now() >= end_) { throw std::runtime_error("overall_budget_expired"); }
    }
    void Apply(HINTERNET request) const {
        Check();
        const auto remaining = std::chrono::duration_cast<std::chrono::milliseconds>(
            end_ - Clock::now()).count();
        const int timeout = static_cast<int>(std::clamp(remaining, 1LL, 8000LL));
        Require(WinHttpSetTimeouts(request, timeout, timeout, timeout, timeout),
                "WinHttpSetTimeouts");
    }
    long long ElapsedMs() const {
        return std::chrono::duration_cast<std::chrono::milliseconds>(
            Clock::now() - start_).count();
    }
private:
    using Clock = std::chrono::steady_clock;
    Clock::time_point start_;
    Clock::time_point end_;
};

void SetDword(HINTERNET handle, DWORD option, DWORD value, const char* operation) {
    Require(WinHttpSetOption(handle, option, &value, sizeof(value)), operation);
}

std::string CertificateSha256(PCCERT_CONTEXT certificate) {
    std::array<BYTE, 32> hash{};
    DWORD size = static_cast<DWORD>(hash.size());
    Require(CryptHashCertificate2(L"SHA256", 0, nullptr,
                                  certificate->pbCertEncoded, certificate->cbCertEncoded,
                                  hash.data(), &size), "certificate_sha256");
    if (size != hash.size()) { throw std::runtime_error("unexpected_sha256_length"); }
    constexpr char digits[] = "0123456789ABCDEF";
    std::string text;
    text.reserve(hash.size() * 2U);
    for (const auto value : hash) {
        text.push_back(digits[value >> 4U]);
        text.push_back(digits[value & 15U]);
    }
    return text;
}

const char* ProtocolName(DWORD protocol) noexcept {
    switch (protocol) {
    case SP_PROT_TLS1_3_CLIENT: return "TLS1.3";
    case SP_PROT_TLS1_2_CLIENT: return "TLS1.2";
    case SP_PROT_TLS1_1_CLIENT: return "TLS1.1";
    case SP_PROT_TLS1_CLIENT: return "TLS1.0";
    default: return "other_platform_value";
    }
}

void PrintSecurity(HINTERNET request) {
    WINHTTP_SECURITY_INFO info{};
    DWORD size = sizeof(info);
    if (WinHttpQueryOption(request, WINHTTP_OPTION_SECURITY_INFO, &info, &size)) {
        std::cout << "tls_info=available protocol=" << ProtocolName(info.ConnectionInfo.dwProtocol)
                  << " protocol_code=0x" << std::hex << info.ConnectionInfo.dwProtocol
                  << " cipher_suite=0x" << info.CipherInfo.dwCipherSuite << std::dec
                  << " cipher_bits=" << info.ConnectionInfo.dwCipherStrength << '\n';
    } else {
        // An unavailable observation does not disable or bypass TLS validation.
        const DWORD error = GetLastError();
        std::cout << "tls_info=unavailable win32_error=" << error << '\n';
    }
    Certificate certificate(request);
    std::cout << "peer_certificate_sha256=" << CertificateSha256(certificate.get()) << '\n';
}

int RunLive() {
    const Budget budget;
    InternetHandle session(WinHttpOpen(L"Sny0StudyHttpsObservation/1.0",
        WINHTTP_ACCESS_TYPE_AUTOMATIC_PROXY, WINHTTP_NO_PROXY_NAME,
        WINHTTP_NO_PROXY_BYPASS, 0), "WinHttpOpen");
    // No advanced HTTP versions: HTTP/1.1 or earlier, checked below.
    SetDword(session.get(), WINHTTP_OPTION_ENABLE_HTTP_PROTOCOL, 0, "http_protocol_policy");
    budget.Apply(session.get());
    InternetHandle connection(WinHttpConnect(session.get(), L"example.com",
        INTERNET_DEFAULT_HTTPS_PORT, 0), "WinHttpConnect");
    InternetHandle request(WinHttpOpenRequest(connection.get(), L"GET", L"/", L"HTTP/1.1",
        WINHTTP_NO_REFERER, WINHTTP_DEFAULT_ACCEPT_TYPES, WINHTTP_FLAG_SECURE),
        "WinHttpOpenRequest");
    SetDword(request.get(), WINHTTP_OPTION_DISABLE_FEATURE,
        WINHTTP_DISABLE_REDIRECTS | WINHTTP_DISABLE_AUTHENTICATION | WINHTTP_DISABLE_COOKIES,
        "disable_redirect_auth_cookies");
    SetDword(request.get(), WINHTTP_OPTION_AUTOLOGON_POLICY,
        WINHTTP_AUTOLOGON_SECURITY_LEVEL_HIGH, "disable_default_credentials");
    // No security-ignore flags, custom trust, client certificate or credentials.
    std::cout << "mode=live target=https://example.com/ api=WinHTTP\n"
              << "certificate_validation=platform_default_no_override\n"
              << "revocation_policy=platform_default_no_explicit_enable\n";
    budget.Apply(request.get());
    Require(WinHttpSendRequest(request.get(), WINHTTP_NO_ADDITIONAL_HEADERS, 0,
        WINHTTP_NO_REQUEST_DATA, 0, 0, 0), "WinHttpSendRequest");
    budget.Check();
    budget.Apply(request.get());
    Require(WinHttpReceiveResponse(request.get(), nullptr), "WinHttpReceiveResponse");
    budget.Check();
    DWORD status = 0;
    DWORD statusSize = sizeof(status);
    Require(WinHttpQueryHeaders(request.get(), WINHTTP_QUERY_STATUS_CODE | WINHTTP_QUERY_FLAG_NUMBER,
        WINHTTP_HEADER_NAME_BY_INDEX, &status, &statusSize, WINHTTP_NO_HEADER_INDEX), "http_status");
    std::array<wchar_t, 32> version{};
    DWORD versionSize = static_cast<DWORD>(sizeof(version));
    Require(WinHttpQueryHeaders(request.get(), WINHTTP_QUERY_VERSION,
        WINHTTP_HEADER_NAME_BY_INDEX, version.data(), &versionSize,
        WINHTTP_NO_HEADER_INDEX), "http_version");
    if (std::wstring_view(version.data()) != L"HTTP/1.1") {
        throw std::runtime_error("unexpected_http_version");
    }
    std::cout << "api_status=response_headers http_version=1.1 http_status=" << status << '\n';
    PrintSecurity(request.get());

    std::array<BYTE, 4096> buffer{};
    std::size_t total = 0;
    std::size_t reads = 0;
    for (;;) {
        budget.Apply(request.get());
        // One extra byte can detect an oversized body even at the limit.
        const DWORD requested = static_cast<DWORD>(std::min(buffer.size(), BodyLimit - total + 1U));
        DWORD received = 0;
        Require(WinHttpReadData(request.get(), buffer.data(), requested, &received), "WinHttpReadData");
        budget.Check();
        ++reads;
        if (received > requested) { throw std::runtime_error("invalid_read_count"); }
        if (received > BodyLimit - total) { throw std::runtime_error("body_limit_exceeded"); }
        total += received;
        if (received == 0) { break; }
    }
    const bool success = status >= 200 && status < 300;
    std::cout << "api_status=response_complete body_bytes=" << total
              << " body_limit=" << BodyLimit << " read_calls=" << reads
              << " elapsed_ms=" << budget.ElapsedMs() << '\n'
              << "http_success=" << (success ? "true" : "false") << '\n';
    return success ? 0 : 1;
}
} // namespace

int main(int argc, char* argv[]) {
    if (argc == 1) {
        std::cout << "usage: https_observation --live\n"
                  << "target=https://example.com/ network_request=not_started\n";
        return 0;
    }
    if (argc != 2 || std::string_view(argv[1]) != "--live") {
        std::cerr << "error=invalid_arguments expected=--live\n";
        return 2;
    }
    try {
        const int result = RunLive();
        std::cout << "caller_scope=finished\n";
        return result;
    } catch (const ApiError& error) {
        std::cerr << "api_status=failed operation=" << error.what()
                  << " win32_error=" << error.code << " caller_scope=finished\n";
    } catch (const std::exception& error) {
        std::cerr << "observation_status=failed reason=" << error.what()
                  << " caller_scope=finished\n";
    }
    return 1;
}

csharp
using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.IO;
using System.Net;
using System.Net.Http;
using System.Net.Security;
using System.Security.Cryptography;
using System.Security.Cryptography.X509Certificates;
using System.Threading;
using System.Threading.Tasks;

internal static class Program
{
    private const int BodyLimit = 64 * 1024;

    private sealed class TlsObservations : IDisposable
    {
        private readonly object gate = new();
        private readonly List<X509Certificate> certificates = new();
        private readonly List<string> snapshots = new();
        private bool disposed;

        public ValueTask<Stream> Observe(SocketsHttpPlaintextStreamFilterContext context,
                                        CancellationToken cancellationToken)
        {
            cancellationToken.ThrowIfCancellationRequested();
            // The handler owns this stream: do not read, replace or dispose it.
            if (context.PlaintextStream is SslStream tls)
            {
                lock (gate)
                {
                    if (disposed) { throw new ObjectDisposedException(nameof(TlsObservations)); }
                    X509Certificate? certificate = tls.RemoteCertificate;
                    // RemoteCertificate transfers certificate disposal responsibility.
                    // Keep it alive until the HTTP client/handler have been disposed.
                    if (certificate is not null &&
                        !certificates.Exists(item => ReferenceEquals(item, certificate)))
                    {
                        certificates.Add(certificate);
                    }
                    if (!tls.IsAuthenticated || !tls.IsEncrypted || certificate is null)
                    {
                        throw new InvalidOperationException("unexpected_tls_state");
                    }
                    string cipher;
                    try { cipher = tls.NegotiatedCipherSuite.ToString(); }
                    catch (PlatformNotSupportedException) { cipher = "unavailable"; }
                    snapshots.Add($"tls_info=available protocol={tls.SslProtocol} " +
                        $"cipher_suite={cipher} negotiated_http={context.NegotiatedHttpVersion}\n" +
                        $"peer_certificate_sha256={certificate.GetCertHashString(HashAlgorithmName.SHA256)}");
                }
            }
            else
            {
                lock (gate)
                {
                    if (disposed) { throw new ObjectDisposedException(nameof(TlsObservations)); }
                    snapshots.Add("tls_info=unavailable reason=not_sslstream");
                }
            }
            return ValueTask.FromResult(context.PlaintextStream);
        }

        public void Print()
        {
            lock (gate)
            {
                Console.WriteLine($"tls_observation_callbacks={snapshots.Count}");
                foreach (string snapshot in snapshots) { Console.WriteLine(snapshot); }
            }
        }

        public void Dispose()
        {
            lock (gate)
            {
                disposed = true;
                foreach (X509Certificate certificate in certificates) { certificate.Dispose(); }
                certificates.Clear();
            }
        }
    }

    private static async Task<int> RunLiveAsync()
    {
        Stopwatch elapsed = Stopwatch.StartNew();
        // Declaration order keeps observed certificates alive beyond handler disposal.
        using TlsObservations observations = new();
        using SocketsHttpHandler handler = new()
        {
            AllowAutoRedirect = false,
            AutomaticDecompression = DecompressionMethods.None,
            UseCookies = false,
            Credentials = null,
            DefaultProxyCredentials = null,
            ConnectTimeout = TimeSpan.FromSeconds(8),
            PlaintextStreamFilter = observations.Observe
        };
        // No certificate-validation callback, protocol override or custom trust.
        using HttpClient client = new(handler, disposeHandler: false)
        {
            Timeout = Timeout.InfiniteTimeSpan
        };
        using CancellationTokenSource cancellation = new(TimeSpan.FromSeconds(30));
        using HttpRequestMessage request = new(HttpMethod.Get, "https://example.com/")
        {
            Version = HttpVersion.Version11,
            VersionPolicy = HttpVersionPolicy.RequestVersionExact
        };
        request.Headers.UserAgent.ParseAdd("Sny0StudyHttpsObservation/1.0");
        Console.WriteLine("mode=live target=https://example.com/ api=HttpClient");
        Console.WriteLine("certificate_validation=platform_default_no_override");
        Console.WriteLine($"revocation_policy={handler.SslOptions.CertificateRevocationCheckMode}");
        using HttpResponseMessage response = await client.SendAsync(request,
            HttpCompletionOption.ResponseHeadersRead, cancellation.Token).ConfigureAwait(false);
        Console.WriteLine($"api_status=response_headers http_version={response.Version} " +
                          $"http_status={(int)response.StatusCode}");
        observations.Print();
        if (response.Version != HttpVersion.Version11)
        {
            throw new InvalidOperationException("unexpected_http_version");
        }
        using Stream body = await response.Content.ReadAsStreamAsync(cancellation.Token).ConfigureAwait(false);
        byte[] buffer = new byte[4096];
        int total = 0;
        int reads = 0;
        while (true)
        {
            // Read one extra byte to detect a body exceeding the cap.
            int requested = Math.Min(buffer.Length, BodyLimit - total + 1);
            int received = await body.ReadAsync(buffer.AsMemory(0, requested), cancellation.Token)
                                     .ConfigureAwait(false);
            ++reads;
            if (received < 0 || received > requested)
            {
                throw new InvalidOperationException("invalid_read_count");
            }
            if (received > BodyLimit - total)
            {
                throw new InvalidOperationException("body_limit_exceeded");
            }
            total += received;
            if (received == 0) { break; }
        }
        Console.WriteLine($"api_status=response_complete body_bytes={total} body_limit={BodyLimit} " +
                          $"read_calls={reads} elapsed_ms={elapsed.ElapsedMilliseconds}");
        Console.WriteLine($"http_success={response.IsSuccessStatusCode.ToString().ToLowerInvariant()}");
        return response.IsSuccessStatusCode ? 0 : 1;
    }

    private static async Task<int> Main(string[] args)
    {
        if (args.Length == 0)
        {
            Console.WriteLine("usage: HttpsObservation --live");
            Console.WriteLine("target=https://example.com/ network_request=not_started");
            return 0;
        }
        if (args.Length != 1 || args[0] != "--live")
        {
            Console.Error.WriteLine("error=invalid_arguments expected=--live");
            return 2;
        }
        try
        {
            int result = await RunLiveAsync().ConfigureAwait(false);
            Console.WriteLine("caller_scope=finished");
            return result;
        }
        catch (OperationCanceledException exception)
        {
            Console.Error.WriteLine($"api_status=cancelled exception={exception.GetType().Name} " +
                                    "caller_scope=finished");
        }
        catch (Exception exception)
        {
            Console.Error.WriteLine($"observation_status=failed exception={exception.GetType().Name} " +
                                    $"hresult=0x{exception.HResult:X8} caller_scope=finished");
        }
        return 1;
    }
