C++とC#でOSの名前解決結果と取消しの境界を観察する ​

名前や数値IPをAPIへ渡し、返されたアドレスとAPIの終端状態を調べます。 DNSパケットを直接送受信する例ではありません。名前解決の経路と図はDNSと名前解決、その後の処理はTCP・HTTPへつながります。

名前解決に成功しても、接続・HTTP応答・TLS認証が成功したわけではありません。このコードはそれらを実行しません。

入力と検査する条件 ​

入力モード成功時の検査
127.0.0.1default / live入力IPv4と同じアドレス・familyが返る
::1default / live入力IPv6と同じアドレス・familyが返る
localhostdefault / live有効なアドレスがあり、loopbackを含む
example.com.--liveのみ少なくとも有効なIPv4/IPv6が得られる

公開名のIP、件数、順序、時刻、処理時間は固定assertしません。localhostのloopback含有はこの教材の検査条件で、任意のローカル設定を強制したり変更したりするコードではありません。example.comはIANAが文書用に維持するドメインで、毎回同じアドレスや稼働状態を期待する運用先ではありません。IANA：Example Domains

defaultは外部名を指定しない範囲です。C++はNS_ALLでOSの名前解決方針を通すため、パケットを測らず「ネットワークへ絶対に出ない」「hostsだけを使った」とは断定しません。C#の数値IP入力は、DNSサーバーへ問い合わせずそのアドレスを返すとAPI文書で説明されています。Microsoft：GetAddrInfoExW、Dns.GetHostAddressesAsync

各言語の3ファイルを、それぞれ同じフォルダへ保存します。ソースと出力はASCIIです。任意のhost入力、独自DNSサーバー、hosts/Firewall等の変更やcache flushは行いません。

8秒は取消要求の期限で、回収は別 ​

C++はGetAddrInfoExWへ、要求専用のゼロ初期化OVERLAPPEDとmanual-reset eventを渡します。pTimeoutはnullptrとし、pendingならイベント待機に8秒の期限を設けます。期限到達時は取消しを要求し、その後も終端完了を待ってGetAddrInfoExOverlappedResultを回収します。名前文字列・hints・result・OVERLAPPED・event・取消handleは、この回収まで保持します。

C++のSOCK_STREAM/IPPROTO_TCPは、返す接続候補に関する条件です。DNSの照会をTCPで送る指定でも、その証拠でもありません。C#のAddressFamily.UnspecifiedもIPv4/IPv6の選択に関するもので、DNSの通信方式の指定ではありません。両APIのヒント・namespace指定は同一ではなく、結果の件数や順序を両言語間で一致assertしません。

GetAddrInfoExCancel成功は利用者向け完了通知を起こし、要求結果はWSA_E_CANCELLEDになります。既に完了/timeoutした競走ではWSA_INVALID_HANDLEが返る場合もあるため、その場合も完了を回収します。内部の同期provider処理は継続し得るので、取消しは内部処理全停止を意味しません。Microsoft：GetAddrInfoExCancel、GetAddrInfoExOverlappedResult

回収後にFreeAddrInfoExWとeventのCloseHandleを行い、全要求を片付けてからWSACleanupします。専用eventの終端確認自体に根本的な異常が起きた場合は、pendingのstack領域を巻き戻さず異常停止する防御経路を置いています。この経路は今回実行していません。

C#はDns.GetHostAddressesAsync(host, AddressFamily.Unspecified, token)を呼び、各要求のCancellationTokenSourceを8秒で取消要求する設定にします。結果、SocketException、OperationCanceledExceptionを一度のawaitで回収してからCTSをdisposeします。Taskの完了と内部OS処理の停止を同じものとしては扱いません。

したがって、8秒は各要求の取消要求期限であり、回収待ちを含む厳密な実時間終了や、プログラム全体が8秒で終わる保証ではありません。Microsoft：取消token付き名前解決

ログで分かること ​

api_statusはAPIの終端状態、validは上表の教材条件に合ったかです。失敗/取消を空の成功結果に変換せず、そのまま報告します。elapsed_msはAPI呼出しとその前後を含む経過時間で、C++では要求ownerの生成等も含みます。DNS通信だけの時間やcache hit判定ではありません。C++のimmediate/pendingと、C#が返却後に調べるcompleted_at_checkも、それぞれのAPI層の観察です。

今回の出力から、数値IPの結果を抜粋します。

text
  address family=IPv4 value=127.0.0.1 scope=0 loopback=true
result=numeric_ipv4 addresses=1 valid=true has_loopback=true numeric_match=true
  address family=IPv6 value=::1 scope=0 loopback=true
result=numeric_ipv6 addresses=1 valid=true has_loopback=true numeric_match=true

今回は両言語でlocalhostから::1と127.0.0.1、公開名から有効なIPv4を2件得ました。これは一環境の観察で、公開名の結果を期待値にはしていません。返された順序、API呼出し回数、所要時間から、A/AAAAのwire照会数やroot/TLD/権威への経路を推定しません。

text
summary api_calls=3 succeeded=3 failed_or_cancelled=0 caller_objects=released
PASS: address validation; no wire/cache/connect claim

liveではapi_calls=4です。この件数はプログラムが呼んだAPIの回数で、DNSパケット数ではありません。caller_objects=releasedも、利用者側要求の寿命と後片付けを終えたことを表し、OS provider全停止や物理資源0、GC回収を証明する値ではありません。

namespace {
constexpr DWORD cancelAfterMs = 8000;
unsigned int callerRequests = 0;
bool cleanupFailed = false;
struct ApiFailure { const char* operation; unsigned long code; };
void require(bool condition, const char* message) {
    if (!condition) throw std::runtime_error(message);
}
class WsaSession {
public:
    WsaSession() {
        WSADATA data{};
        const int code = WSAStartup(MAKEWORD(2, 2), &data);
        if (code != 0) throw ApiFailure{"WSAStartup", static_cast<unsigned long>(code)};
        if (LOBYTE(data.wVersion) != 2 || HIBYTE(data.wVersion) != 2) {
            if (WSACleanup() == SOCKET_ERROR) cleanupFailed = true;
            throw std::runtime_error("Winsock 2.2 unavailable");
        }
    }
    ~WsaSession() noexcept {
        if (WSACleanup() == SOCKET_ERROR) {
            cleanupFailed = true;
            std::fprintf(stderr, "CLEANUP FAIL: WSACleanup code=%d\n", WSAGetLastError());
        }
    }
    WsaSession(const WsaSession&) = delete;
    WsaSession& operator=(const WsaSession&) = delete;
};

// Every caller-owned parameter remains at a stable address until terminal completion.
struct QueryOwner {
    std::wstring name;
    ADDRINFOEXW hints{};
    PADDRINFOEXW results = nullptr;
    OVERLAPPED operation{};
    HANDLE cancelHandle = nullptr; // Opaque cancellation handle; do not CloseHandle it.
    HANDLE event = nullptr;
    bool pending = false;
    QueryOwner(const wchar_t* input, bool numeric) : name(input) {
        event = CreateEventW(nullptr, TRUE, FALSE, nullptr);
        if (!event) throw ApiFailure{"CreateEventW", GetLastError()};
        operation.hEvent = event;
        hints.ai_family = AF_UNSPEC;
        hints.ai_socktype = SOCK_STREAM;
        hints.ai_protocol = IPPROTO_TCP;
        hints.ai_flags = numeric ? AI_NUMERICHOST : 0;
        ++callerRequests;
    }
    ~QueryOwner() noexcept {
        // A fundamental wait/handle failure must not unwind still-pending storage.
        if (pending) std::abort();
        if (results) FreeAddrInfoExW(results);
        if (!CloseHandle(event)) {
            cleanupFailed = true;
            std::fprintf(stderr, "CLEANUP FAIL: CloseHandle code=%lu\n", GetLastError());
        }
        --callerRequests;
    }
    QueryOwner(const QueryOwner&) = delete;
    QueryOwner& operator=(const QueryOwner&) = delete;
};

struct Outcome {
    int code = 0;
    int cancelCode = 0;
    DWORD waitError = 0;
    bool wasPending = false;
    bool cancelRequested = false;
    bool cancelDeadlineReached = false;
};
[[noreturn]] void failWithoutUnwinding(const char* message) noexcept {
    std::fprintf(stderr, "FATAL: %s; pending caller storage cannot be released\n", message);
    std::abort();
}
Outcome issueAndDrain(QueryOwner& query) noexcept {
    Outcome outcome;
    // pTimeout=nullptr: use one caller cancellation-request deadline, then drain.
    const int start = GetAddrInfoExW(query.name.c_str(), nullptr, NS_ALL, nullptr, &query.hints,
        &query.results, nullptr, &query.operation, nullptr, &query.cancelHandle);
    if (start != WSA_IO_PENDING) {
        outcome.code = start; // Immediate success or direct failure, no pending request.
        return outcome;
    }
    outcome.wasPending = true;
    query.pending = true;
    DWORD waited = WaitForSingleObject(query.event, cancelAfterMs);
    if (waited != WAIT_OBJECT_0) {
        outcome.cancelDeadlineReached = waited == WAIT_TIMEOUT;
        outcome.waitError = waited == WAIT_FAILED ? GetLastError() : 0;
        outcome.cancelRequested = true;
        outcome.cancelCode = GetAddrInfoExCancel(&query.cancelHandle);
        // Cancel success signals user completion. Already-completed races may give
        // WSA_INVALID_HANDLE. Either way collect completion before releasing owners.
        waited = WaitForSingleObject(query.event, INFINITE);
        if (waited != WAIT_OBJECT_0) failWithoutUnwinding("Completion drain wait failed");
    }
    outcome.code = GetAddrInfoExOverlappedResult(&query.operation);
    if (outcome.code == WSAEINPROGRESS) failWithoutUnwinding("Event did not establish terminal completion");
    query.pending = false;
    return outcome;
}

struct AddressSummary {
    unsigned int count = 0;
    bool allValid = true;
    bool allMatchNumeric = true;
    bool hasLoopback = false;
};
AddressSummary inspect(const QueryOwner& query, int numericFamily) {
    AddressSummary summary;
    for (const ADDRINFOEXW* entry = query.results; entry; entry = entry->ai_next) {
        std::array<char, INET6_ADDRSTRLEN> text{};
        bool valid = false, loopback = false, numericMatch = false;
        unsigned long scope = 0;
        const char* family = "other";
        if (entry->ai_family == AF_INET && entry->ai_addr && entry->ai_addrlen >= sizeof(sockaddr_in)) {
            const auto* address = reinterpret_cast<const sockaddr_in*>(entry->ai_addr);
            family = "IPv4";
            valid = InetNtopA(AF_INET, const_cast<IN_ADDR*>(&address->sin_addr), text.data(), text.size()) != nullptr;
            loopback = (ntohl(address->sin_addr.s_addr) >> 24U) == 127U;
            numericMatch = numericFamily == AF_INET && address->sin_addr.s_addr == htonl(INADDR_LOOPBACK);
        } else if (entry->ai_family == AF_INET6 && entry->ai_addr && entry->ai_addrlen >= sizeof(sockaddr_in6)) {
            const auto* address = reinterpret_cast<const sockaddr_in6*>(entry->ai_addr);
            family = "IPv6";
            valid = InetNtopA(AF_INET6, const_cast<IN6_ADDR*>(&address->sin6_addr), text.data(), text.size()) != nullptr;
            loopback = IN6_IS_ADDR_LOOPBACK(&address->sin6_addr) != 0;
            numericMatch = numericFamily == AF_INET6 && loopback;
            scope = address->sin6_scope_id;
        }
        ++summary.count;
        summary.allValid = summary.allValid && valid;
        summary.hasLoopback = summary.hasLoopback || loopback;
        if (numericFamily != AF_UNSPEC) summary.allMatchNumeric = summary.allMatchNumeric && numericMatch;
        std::printf("  address family=%s value=%s scope=%lu loopback=%s\n", family,
            valid ? text.data() : "invalid", scope, loopback ? "true" : "false");
    }
    return summary;
}
bool observe(const wchar_t* input, const char* label, int numericFamily, bool localhost) {
    const auto started = std::chrono::steady_clock::now();
    QueryOwner query(input, numericFamily != AF_UNSPEC);
    const Outcome outcome = issueAndDrain(query);
    const double elapsed = std::chrono::duration<double, std::milli>(std::chrono::steady_clock::now() - started).count();
    const char* status = outcome.code == 0 ? "success" : outcome.code == WSA_E_CANCELLED
        ? "cancelled" : outcome.code == WSAETIMEDOUT ? "resolver_timeout" : "resolver_failure";
    if (outcome.waitError != 0) status = "wait_failure_after_drain";
    std::printf("query=%s start=%s api_status=%s code=%d cancel_requested=%s cancel_code=%d cancel_deadline_reached=%s elapsed_ms=%.3f\n",
        label, outcome.wasPending ? "pending" : "immediate", status, outcome.code,
        outcome.cancelRequested ? "true" : "false", outcome.cancelCode,
        outcome.cancelDeadlineReached ? "true" : "false", elapsed);
    if (outcome.code != 0 || outcome.waitError != 0) return false;
    const AddressSummary result = inspect(query, numericFamily);
    const bool valid = result.count > 0 && result.allValid
        && (numericFamily == AF_UNSPEC || result.allMatchNumeric) && (!localhost || result.hasLoopback);
    std::printf("result=%s addresses=%u valid=%s has_loopback=%s numeric_match=%s\n", label, result.count,
        valid ? "true" : "false", result.hasLoopback ? "true" : "false",
        numericFamily == AF_UNSPEC ? "n/a" : result.allMatchNumeric ? "true" : "false");
    return valid;
}
} // namespace
int wmain(int argc, wchar_t* argv[]) {
    const bool live = argc == 2 && std::wcscmp(argv[1], L"--live") == 0;
    if (argc != 1 && !live) {
        std::fputs("usage: name_resolution_observation.exe [--live]\n", stderr);
        return 2;
    }
    try {
        unsigned int succeeded = 0;
        const unsigned int apiCalls = live ? 4U : 3U;
        {
            const WsaSession session;
            std::printf("mode=%s cancel_request_deadline_seconds=8 per_query=true namespace=NS_ALL\n", live ? "live" : "default");
            if (observe(L"127.0.0.1", "numeric_ipv4", AF_INET, false)) ++succeeded;
            if (observe(L"::1", "numeric_ipv6", AF_INET6, false)) ++succeeded;
            if (observe(L"localhost", "localhost", AF_UNSPEC, true)) ++succeeded;
            if (live && observe(L"example.com.", "example.com.", AF_UNSPEC, false)) ++succeeded;
            require(callerRequests == 0, "Caller request owners still live");
        }
        std::printf("summary api_calls=%u succeeded=%u failed_or_cancelled=%u caller_objects=released\n",
            apiCalls, succeeded, apiCalls - succeeded);
        if (cleanupFailed || succeeded != apiCalls) return 1;
        std::puts("PASS: address validation; no wire/cache/connect claim");
        return 0;
    } catch (const ApiFailure& error) {
        std::fprintf(stderr, "FAIL: %s code=%lu\n", error.operation, error.code); return 1;
    } catch (const std::exception& error) {
        std::fprintf(stderr, "FAIL: %s\n", error.what()); return 1;
    }
}

using System;
using System.Diagnostics;
using System.Globalization;
using System.Linq;
using System.Net;
using System.Net.Sockets;
using System.Threading;
using System.Threading.Tasks;

internal static class Program
{
    private static async Task<bool> ObserveAsync(string input, string label, IPAddress? numeric, bool localhost)
    {
        // Eight seconds requests cancellation. Await still consumes terminal completion;
        // this is not a hard wall-clock limit or a claim that all OS work has stopped.
        using var cancellation = new CancellationTokenSource(TimeSpan.FromSeconds(8));
        var stopwatch = Stopwatch.StartNew();
        bool completedAtCheck = false;
        IPAddress[] addresses;
        try
        {
            Task<IPAddress[]> request = Dns.GetHostAddressesAsync(input, AddressFamily.Unspecified, cancellation.Token);
            completedAtCheck = request.IsCompleted;
            addresses = await request.ConfigureAwait(false);
            stopwatch.Stop();
        }
        catch (OperationCanceledException)
        {
            stopwatch.Stop();
            Console.WriteLine($"query={label} completed_at_check={Text(completedAtCheck)} api_status=cancelled code=OperationCanceledException cancel_requested={Text(cancellation.IsCancellationRequested)} elapsed_ms={stopwatch.Elapsed.TotalMilliseconds:F3}");
            return false;
        }
        catch (SocketException error)
        {
            stopwatch.Stop();
            string status = error.SocketErrorCode == SocketError.TimedOut ? "resolver_timeout" : "resolver_failure";
            Console.WriteLine($"query={label} completed_at_check={Text(completedAtCheck)} api_status={status} code={error.NativeErrorCode} cancel_requested={Text(cancellation.IsCancellationRequested)} elapsed_ms={stopwatch.Elapsed.TotalMilliseconds:F3}");
            return false;
        }
        Console.WriteLine($"query={label} completed_at_check={Text(completedAtCheck)} api_status=success code=0 cancel_requested={Text(cancellation.IsCancellationRequested)} elapsed_ms={stopwatch.Elapsed.TotalMilliseconds:F3}");
        bool allValid = true;
        foreach (IPAddress address in addresses)
        {
            bool valid = address.AddressFamily is AddressFamily.InterNetwork or AddressFamily.InterNetworkV6;
            allValid &= valid;
            string family = address.AddressFamily == AddressFamily.InterNetwork ? "IPv4"
                : address.AddressFamily == AddressFamily.InterNetworkV6 ? "IPv6" : "other";
            long scope = address.AddressFamily == AddressFamily.InterNetworkV6 ? address.ScopeId : 0;
            Console.WriteLine($"  address family={family} value={address} scope={scope} loopback={Text(IPAddress.IsLoopback(address))}");
        }
        bool numericMatch = numeric is null || addresses.All(address => address.AddressFamily == numeric.AddressFamily && address.Equals(numeric));
        bool hasLoopback = addresses.Any(IPAddress.IsLoopback);
        bool validResult = addresses.Length > 0 && allValid && numericMatch && (!localhost || hasLoopback);
        string numericText = numeric is null ? "n/a" : Text(numericMatch);
        Console.WriteLine($"result={label} addresses={addresses.Length} valid={Text(validResult)} has_loopback={Text(hasLoopback)} numeric_match={numericText}");
        return validResult;
    }
    private static string Text(bool value) => value ? "true" : "false";
    private static async Task<int> Main(string[] args)
    {
        bool live = args.Length == 1 && args[0] == "--live";
        if (args.Length != 0 && !live)
        {
            Console.Error.WriteLine("usage: NameResolutionObservation [--live]");
            return 2;
        }
        try
        {
            CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;
            Console.WriteLine($"mode={(live ? "live" : "default")} cancel_request_deadline_seconds=8 per_query=true family=Unspecified");
            int succeeded = 0;
            int apiCalls = live ? 4 : 3;
            if (await ObserveAsync("127.0.0.1", "numeric_ipv4", IPAddress.Loopback, false)) ++succeeded;
            if (await ObserveAsync("::1", "numeric_ipv6", IPAddress.IPv6Loopback, false)) ++succeeded;
            if (await ObserveAsync("localhost", "localhost", null, true)) ++succeeded;
            if (live && await ObserveAsync("example.com.", "example.com.", null, false)) ++succeeded;
            Console.WriteLine($"summary api_calls={apiCalls} succeeded={succeeded} failed_or_cancelled={apiCalls - succeeded} caller_objects=released");
            if (succeeded != apiCalls) return 1;
            Console.WriteLine("PASS: address validation; no wire/cache/connect claim");
            return 0;
        }
        catch (Exception error)
        {
            Console.Error.WriteLine("FAIL: " + error.GetType().Name);
            return 1;
        }
    }
