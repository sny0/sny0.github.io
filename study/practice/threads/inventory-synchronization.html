C++とC#で在庫の確認・更新を一つのロックで守る ​

在庫があるか確認してから消費するまでを、一つのcritical sectionにします。 初期在庫17件に対して4 workerが各10回試し、remaining >= 0とremaining + consumed == initialを保てるか確認します。同期の概念と図はスレッド同期を参照してください。

何をどの方法で守るか ​

対象このサンプルの扱い
在庫の残数・消費数同じmutex / lockで確認と両方の更新をまとめる
Snapshot同じlock内で両方の値をコピーし、lockを解放してから検査する
workerごとの結果・例外起動前に専用slotを用意し、各slotは担当workerだけが書く
親からの結果read・表示全workerのjoin後に行う

Snapshotはコピーした時点で整合する値です。TryConsumeと次のSnapshotの間には他workerが動けるため、「そのworkerの消費直後の状態」とは限りません。

C++はstd::mutexとstd::lock_guardを使います。mutexのunlockと、同じmutexを取得する後続lockの同期を利用し、guardのスコープを抜けるとunlockします。C++20草案 N4861：mutex、lock_guard

C#はprivate readonly objectに対するlockなのでMonitor経路です。System.Threading.Lock型を使う新しい経路とは区別します。Monitorは同じthreadから再入できますが、C++のstd::mutexにはその性質を当てはめられません。この例はlock中に別のlock取得メソッドを呼ばず、再入を必要としません。Microsoft：lock文

確認と更新を分割すると何が起こるか ​

次は在庫1件で、確認と更新を別々のcritical sectionに分けた場合の論理的競合の概念図です。各read・更新を個別にロックしていても、確認結果が更新時まで有効とは限りません。この誤った版は実行していません。

順worker Aworker B残数
1残数1を確認しlock解放1
2残数1を確認しlock解放1
3再lockし、再確認せず減算0
4再lockし、再確認せず減算-1

サンプルのTryConsumeでは「確認→減算→消費数加算」を同じlock内に置くので、この分割を作りません。なおC++で共有値を同期せずread/writeするdata raceは未定義動作であり、上のような特定の結果になるという予測はできません。N4861：data races

各言語の3ファイルを、それぞれ同じフォルダへ保存します。ソースとconsole出力はASCIIです。入力・アプリによるファイルI/O・ネットワーク処理・外部ライブラリは使いません。

通常経路ではstd::jthread::joinを明示的に呼び、完了と同期してから親がslotを読みます。途中でスレッド生成が失敗した場合も、内側のjthread群が先に破棄され、既存workerをjoinしてから共有在庫と結果slotを破棄します。destructorはjoinableならstopを要求してjoinしますが、この例のworkerはstop待ちをせず、最大10回の処理を終えて戻ります。worker例外は各slotのexception_ptrに捕捉し、join後に親で再throwします。N4861：jthread::join、jthreadの構築・破棄

どちらもworker内では表示せず、開始gate・sleep・busy wait・乱数も使いません。生成できなかったworkerを待つ仕組みはありません。workerの処理回数は有限ですが、スケジューラやmutex待ちを含む終了時間の上限・公平性は保証しません。

実測結果と確認範囲 ​

2026-11-04、Windows x64（25H2、build 26200.9711）で両言語を各5回実行しました。すべて終了コード0、13 parent checksと40 worker snapshotsの検査に成功し、最終行の値は各回共通でした。

text
final: remaining=0 consumed=17 total_success=17 total_fail=23 total_attempts=40 snapshots=40
PASS: 13 parent checks; 40 worker snapshots validated

13項目は単一threadでの空在庫・1件消費・再消費拒否・負の初期値拒否など6項目、4 worker各slotの合計4項目、最終状態・総試行数など3項目です。workerは各試行後のSnapshotでも不変条件を検査します。

worker別の成功配分は実際に変化しました。表示は親がslot番号順に並べたもので、実行順ではありません。 成功者や順序を固定した期待値にはしていません。

実装 ​

C++20 ​

cpp
#include <array>
#include <cstdio>
#include <exception>
#include <mutex>
#include <stdexcept>
#include <thread>
#include <vector>

namespace {
constexpr int initialStock = 17;
constexpr int workerCount = 4;
constexpr int attemptsPerWorker = 10;
unsigned int checks = 0;

struct InventorySnapshot {
    int remaining;
    int consumed;
};

class Inventory {
public:
    explicit Inventory(int initial) : remaining_(initial) {
        if (initial < 0) throw std::invalid_argument("Negative initial stock");
    }

    bool tryConsume() {
        const std::lock_guard lock(mutex_);
        // Check and both updates form one critical section.
        if (remaining_ == 0) return false;
        --remaining_;
        ++consumed_;
        return true;
    }

    InventorySnapshot snapshot() const {
        const std::lock_guard lock(mutex_);
        return {remaining_, consumed_}; // Copy while holding the same mutex.
    }

private:
    mutable std::mutex mutex_;
    int remaining_;
    int consumed_ = 0;
};

struct WorkerResult {
    int successes = 0;
    int failures = 0;
    int snapshotChecks = 0;
    std::exception_ptr error;
};

void check(bool condition, const char* message) {
    if (!condition) throw std::runtime_error(message);
    ++checks; // Only the parent thread calls this function.
}

void runWorker(Inventory& inventory, WorkerResult& result) noexcept {
    try {
        for (int attempt = 0; attempt < attemptsPerWorker; ++attempt) {
            if (inventory.tryConsume()) ++result.successes;
            else ++result.failures;

            const InventorySnapshot state = inventory.snapshot();
            if (state.remaining < 0 || state.remaining + state.consumed != initialStock) {
                throw std::runtime_error("Worker snapshot invariant failed");
            }
            ++result.snapshotChecks;
        }
    } catch (...) {
        result.error = std::current_exception();
    }
}

void checkSingleThreadCases() {
    Inventory empty(0);
    check(!empty.tryConsume(), "Empty inventory must reject consumption");
    const InventorySnapshot emptyState = empty.snapshot();
    check(emptyState.remaining == 0 && emptyState.consumed == 0, "Empty snapshot");

    Inventory one(1);
    check(one.tryConsume(), "First consumption must succeed");
    check(!one.tryConsume(), "Second consumption must fail");
    const InventorySnapshot oneState = one.snapshot();
    check(oneState.remaining == 0 && oneState.consumed == 1, "One-item snapshot");

    bool rejected = false;
    try {
        Inventory invalid(-1);
    } catch (const std::invalid_argument&) {
        rejected = true;
    }
    check(rejected, "Negative initial stock must throw");
    std::puts("single_thread_cases: passed");
}

void observeWorkers() {
    // Shared objects outlive the inner thread scope, including during unwinding.
    Inventory inventory(initialStock);
    std::array<WorkerResult, workerCount> results{};
    {
        std::vector<std::jthread> workers;
        workers.reserve(workerCount);
        for (std::size_t index = 0; index < results.size(); ++index) {
            workers.emplace_back([&inventory, &results, index] {
                runWorker(inventory, results[index]);
            });
        }
        // If construction throws, existing jthreads are joined by destruction.
        // Workers do not wait for a start gate or for any not-yet-created worker.
        for (std::jthread& worker : workers) worker.join();
    }

    // join completed before the parent reads any worker-owned result slot.
    int successes = 0;
    int failures = 0;
    int snapshotChecks = 0;
    for (std::size_t index = 0; index < results.size(); ++index) {
        const WorkerResult& result = results[index];
        if (result.error) std::rethrow_exception(result.error);
        check(result.successes >= 0 && result.failures >= 0
            && result.successes + result.failures == attemptsPerWorker
            && result.snapshotChecks == attemptsPerWorker, "Worker result totals");
        successes += result.successes;
        failures += result.failures;
        snapshotChecks += result.snapshotChecks;
        std::printf("worker %zu: success=%d fail=%d snapshots=%d\n",
            index, result.successes, result.failures, result.snapshotChecks);
    }

    const InventorySnapshot finalState = inventory.snapshot();
    check(successes + failures == workerCount * attemptsPerWorker, "Total attempts");
    check(finalState.remaining >= 0
        && finalState.remaining + finalState.consumed == initialStock, "Final invariant");
    check(successes == initialStock && failures == 23
        && finalState.remaining == 0 && finalState.consumed == successes,
        "Expected final inventory and success/failure counts");
    std::printf("final: remaining=%d consumed=%d total_success=%d total_fail=%d total_attempts=%d snapshots=%d\n",
        finalState.remaining, finalState.consumed, successes, failures,
        successes + failures, snapshotChecks);
}
} // namespace

int main() {
    try {
        std::printf("inventory synchronization: initial=%d workers=%d attempts_per_worker=%d\n",
            initialStock, workerCount, attemptsPerWorker);
        checkSingleThreadCases();
        observeWorkers();
        std::printf("PASS: %u parent checks; 40 worker snapshots validated\n", checks);
        return 0;
    } catch (const std::exception& error) {
        std::fprintf(stderr, "FAIL: %s\n", error.what());
        return 1;
    } catch (...) {
        std::fputs("FAIL: non-standard exception\n", stderr);
        return 1;
    }
}

C# ​

csharp
using System;
using System.Globalization;
using System.Runtime.InteropServices;
using System.Threading;

internal static class Program
{
    private const int InitialStock = 17;
    private const int WorkerCount = 4;
    private const int AttemptsPerWorker = 10;
    private static int checks;

    private readonly struct InventorySnapshot
    {
        public int Remaining { get; }
        public int Consumed { get; }
        public InventorySnapshot(int remaining, int consumed)
        {
            Remaining = remaining;
            Consumed = consumed;
        }
    }

    private sealed class Inventory
    {
        // An object-typed lock uses Monitor, not System.Threading.Lock.EnterScope.
        private readonly object gate = new object();
        private int remaining;
        private int consumed;

        public Inventory(int initial)
        {
            if (initial < 0) throw new ArgumentOutOfRangeException(nameof(initial));
            remaining = initial;
        }

        public bool TryConsume()
        {
            lock (gate)
            {
                // Check and both updates form one critical section.
                if (remaining == 0) return false;
                --remaining;
                ++consumed;
                return true;
            }
        }

        public InventorySnapshot Snapshot()
        {
            lock (gate)
            {
                return new InventorySnapshot(remaining, consumed);
            }
        }
    }

    private sealed class WorkerResult
    {
        public int Successes;
        public int Failures;
        public int SnapshotChecks;
        public Exception? Error;
    }

    private static void Check(bool condition, string message)
    {
        if (!condition) throw new InvalidOperationException(message);
        ++checks; // Only the parent thread calls this function.
    }

    private static void RunWorker(Inventory inventory, WorkerResult result)
    {
        try
        {
            for (int attempt = 0; attempt < AttemptsPerWorker; ++attempt)
            {
                if (inventory.TryConsume()) ++result.Successes;
                else ++result.Failures;

                InventorySnapshot state = inventory.Snapshot();
                if (state.Remaining < 0 || state.Remaining + state.Consumed != InitialStock)
                    throw new InvalidOperationException("Worker snapshot invariant failed");
                ++result.SnapshotChecks;
            }
        }
        catch (Exception error)
        {
            result.Error = error;
        }
    }

    private static void CheckSingleThreadCases()
    {
        var empty = new Inventory(0);
        Check(!empty.TryConsume(), "Empty inventory must reject consumption");
        InventorySnapshot emptyState = empty.Snapshot();
        Check(emptyState.Remaining == 0 && emptyState.Consumed == 0, "Empty snapshot");

        var one = new Inventory(1);
        Check(one.TryConsume(), "First consumption must succeed");
        Check(!one.TryConsume(), "Second consumption must fail");
        InventorySnapshot oneState = one.Snapshot();
        Check(oneState.Remaining == 0 && oneState.Consumed == 1, "One-item snapshot");

        bool rejected = false;
        try
        {
            _ = new Inventory(-1);
        }
        catch (ArgumentOutOfRangeException)
        {
            rejected = true;
        }
        Check(rejected, "Negative initial stock must throw");
        Console.WriteLine("single_thread_cases: passed");
    }

    private static void ObserveWorkers()
    {
        var inventory = new Inventory(InitialStock);
        var results = new WorkerResult[WorkerCount];
        var workers = new Thread[WorkerCount];
        for (int index = 0; index < WorkerCount; ++index)
            results[index] = new WorkerResult();

        int started = 0;
        try
        {
            for (int index = 0; index < WorkerCount; ++index)
            {
                WorkerResult slot = results[index]; // One preallocated slot per worker.
                var worker = new Thread(() => RunWorker(inventory, slot));
                worker.IsBackground = false;
                workers[index] = worker;
                worker.Start();
                ++started;
            }
        }
        finally
        {
            // Construction/Start failure still joins every successfully started worker.
            // No worker waits for a start gate or a not-yet-created worker.
            for (int index = 0; index < started; ++index)
                workers[index].Join();
        }

        // Join completed before the parent reads any worker-owned result slot.
        int successes = 0;
        int failures = 0;
        int snapshotChecks = 0;
        for (int index = 0; index < WorkerCount; ++index)
        {
            WorkerResult result = results[index];
            if (result.Error is not null)
                throw new InvalidOperationException("Worker failed", result.Error);
            Check(result.Successes >= 0 && result.Failures >= 0
                && result.Successes + result.Failures == AttemptsPerWorker
                && result.SnapshotChecks == AttemptsPerWorker, "Worker result totals");
            successes += result.Successes;
            failures += result.Failures;
            snapshotChecks += result.SnapshotChecks;
            Console.WriteLine($"worker {index}: success={result.Successes} fail={result.Failures} snapshots={result.SnapshotChecks}");
        }

        InventorySnapshot finalState = inventory.Snapshot();
        Check(successes + failures == WorkerCount * AttemptsPerWorker, "Total attempts");
        Check(finalState.Remaining >= 0 && finalState.Remaining + finalState.Consumed == InitialStock,
            "Final invariant");
        Check(successes == InitialStock && failures == 23
            && finalState.Remaining == 0 && finalState.Consumed == successes,
            "Expected final inventory and success/failure counts");
        Console.WriteLine($"final: remaining={finalState.Remaining} consumed={finalState.Consumed} total_success={successes} total_fail={failures} total_attempts={successes + failures} snapshots={snapshotChecks}");
    }

    private static int Main()
    {
        try
        {
            CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;
            Console.WriteLine(RuntimeInformation.FrameworkDescription);
            Console.WriteLine($"inventory synchronization: initial={InitialStock} workers={WorkerCount} attempts_per_worker={AttemptsPerWorker}");
            CheckSingleThreadCases();
            ObserveWorkers();
            Console.WriteLine($"PASS: {checks} parent checks; 40 worker snapshots validated");
            return 0;
        }
        catch (Exception error)
        {
            Console.Error.WriteLine("FAIL: " + error.GetType().Name);
            return 1;
        }
    }
}
