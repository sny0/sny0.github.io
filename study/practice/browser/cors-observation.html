ブラウザで同一オリジンとCORSの応答を比べる ​

同じ固定テキストを、通常のページと sandbox="allow-scripts" のiframeから取得します。iframeのURLはページと同じ配信元にありますが、sandboxによって文書には独立したopaque originが割り当てられます。変えるのは要求を開始する文書、fetchのmode、カスタムヘッダーの有無です。オリジンの境界とpreflightの図は辞典記事にあります。同一オリジンポリシーとCORS

CORSの実験ページを新しいタブで開く

公開版で4つの要求を比べる ​

操作要求元と設定この配信での観測の目安
通常ページからGET親ページ、同一オリジンbasic、status 200、本文を読める
別オリジンからCORS GETsandbox内、mode: "cors"、追加ヘッダーなし応答の Access-Control-Allow-Origin: * により cors、status 200、本文を読める
別オリジンからno-cors GETsandbox内、mode: "no-cors"opaque、status 0。JavaScriptに公開される本文とヘッダーはない
カスタムヘッダー付きGETsandbox内、mode: "cors"、X-Study-Demo 付き先にpreflightのOPTIONSが出る。公開先がOPTIONSを405で拒否すると、GETへ進まず fetch() が失敗する

すべて固定のGETで、credentials: "omit" を使います。公開版の結果は実際のブラウザと配信先の応答に従います。status 0はopaqueな Response のJavaScript上の値です。通信失敗でPromiseがrejectされた場合は Response 自体を受け取れません。Fetch Standardのfiltered response

別オリジンの no-cors では redirect: "follow" を指定します。この組み合わせで redirect: "error" を使うと、ブラウザは取得を始める前に失敗を返します。Fetch StandardのMain fetch

NetworkでOPTIONSとGETを分けて見る ​

  1. 開発者ツールのNetworkを開き、payload.txt で絞り込みます。結果を見比べるときはログを一度消します。
  2. 「別オリジンからCORS GET」を押します。要求の Origin: null と応答の Access-Control-Allow-Origin を確認します。表示上の null はopaque originをHTTPへ直列化した値です。この実験の no-cors のGETでは通常 Origin が付きません。
  3. 「カスタムヘッダー付きGET」を押します。事前確認の許可がキャッシュされていなければ、先にOPTIONSが送られます。Access-Control-Request-Method: GET と Access-Control-Request-Headers: x-study-demo を確認します。失敗時は、Network上で実際のGETに応答があるかを分けて確認します。ブラウザによっては、送信されなかったGETも失敗した要求として一覧に出ます。

実験画面は、JavaScriptから観測できた値を表示します。rejectされた理由の切り分けにはNetworkとConsoleを使います。CORS、DNS、接続の失敗はいずれも fetch() の失敗として現れます。Fetch Standardのpreflight

次の9ファイルを同じフォルダに置きます。ブラウザからはHTTPまたはHTTPSで開きます。

  • styles.css
  • main.js

Python 3があれば、まず配布フォルダで次を実行し、http://127.0.0.1:4176/index.html を開きます。

powershell
python server.py --policy deny --port 4176
--policy固定テキストのGETカスタムヘッダーのpreflight
denyHTTP 200、CORS許可ヘッダーなし。別オリジンの mode: "cors" はrejectされる拒否
readHTTP 200、Access-Control-Allow-Origin: *。別オリジンのCORS GETから本文を読める拒否
preflightread と同じ対象のOPTIONSに204で許可を返し、その後のGETへ進む

サーバーをCtrl+Cで停止してから、--policy を変えて再起動し、ページを再読み込みします。まず deny で通常ページとsandboxからGETします。ターミナルにはどちらのGETも記録されます。sandbox側のCORS GETは、サーバーで200が記録されてもページから応答を読めません。次に preflight でカスタムヘッダー付きGETを押し、OPTIONSとGETの両方をターミナルで確認します。

サーバーは 127.0.0.1 にbindし、固定の教材ファイルと応答を配信します。実験中のGETとOPTIONSに対してターミナルへ観測用ログを出します。

コードで確認するところ ​

親ページは自分で同一オリジンのGETを実行し、別オリジンのケースごとに新しいsandbox付きiframeを作ります。親側はメッセージの送信元ウィンドウと event.origin、実行したケースの名前、データの形を確認します。子側は配信URLのオリジンを送信先として指定し、本文とstatusなどの観測結果だけを返します。複数のopaque originは同じ文字列 "null" で表されるため、文字列の一致だけで送信元を判断できません。HTML StandardのWindow間メッセージ通信

各ケースに共通するfetch ​

js
"use strict";

const PayloadUrl = new URL("payload.txt", location.href);
const ObservationMessage = "sny0-study:cors-observation";

async function observeFetch(options) {
  const controller = new AbortController();
  const timeout = setTimeout(() => controller.abort(), 5000);

  try {
    const response = await fetch(PayloadUrl, {
      ...options,
      cache: "no-store",
      credentials: "omit",
      // Cross-origin no-cors requires the follow redirect mode.
      redirect: options.mode === "no-cors" ? "follow" : "error",
      signal: controller.signal,
    });
    return {
      kind: "response",
      type: response.type,
      status: response.status,
      body: response.type === "opaque" ? null : (await response.text()).trimEnd().slice(0, 120),
    };
  } catch {
    return {kind: controller.signal.aborted ? "timeout" : "failed"};
  } finally {
    clearTimeout(timeout);
  }
}

通常ページ ​

js
"use strict";

const Panels = [...document.querySelectorAll("[data-case]")];
const Buttons = Panels.map(panel => panel.querySelector("button"));

document.querySelector("#page-origin").textContent = window.origin;
document.querySelector("#payload-url").textContent = PayloadUrl.href;

function isFrameResult(result) {
  if (!result || typeof result !== "object") {
    return false;
  }
  if (result.kind === "failed" || result.kind === "timeout") {
    return true;
  }
  if (result.kind !== "response") {
    return false;
  }
  if (result.type === "opaque") {
    return result.status === 0 && result.body === null;
  }
  return result.type === "cors" && Number.isInteger(result.status)
    && result.status >= 200 && result.status <= 599
    && typeof result.body === "string" && result.body.length <= 120;
}

function observeInFrame(caseName) {
  return new Promise(resolve => {
    const frame = document.createElement("iframe");
    frame.title = "固定テキスト取得用のサンドボックス";
    frame.hidden = true;
    frame.setAttribute("sandbox", "allow-scripts");
    frame.src = new URL(`frame.html#${caseName}`, location.href);

    function finish(result) {
      clearTimeout(timeout);
      window.removeEventListener("message", receive);
      frame.remove();
      resolve(result);
    }

    function receive(event) {
      if (event.source !== frame.contentWindow || event.origin !== "null") {
        return;
      }
      const data = event.data;
      if (data?.message === ObservationMessage && data.caseName === caseName && isFrameResult(data.result)) {
        finish(data.result);
      }
    }

    const timeout = setTimeout(() => finish({kind: "frame-timeout"}), 8000);
    window.addEventListener("message", receive);
    document.body.append(frame);
  });
}

function showResult(panel, result) {
  const messages = {
    pending: "取得中",
    failed: "Fetchまたは本文の読み取りに失敗",
    timeout: "取得をタイムアウトで中止",
    "frame-timeout": "iframeからの観測結果を待つ時間を超過",
  };
  const hasResponse = result.kind === "response";
  const isOpaque = result.type === "opaque";
  let message = messages[result.kind];
  if (hasResponse) {
    message = isOpaque ? "応答の詳細は非公開" : "応答を読み取り可能";
  }

  panel.dataset.resultKind = result.kind;
  panel.querySelector("[data-result]").textContent = message;
  panel.querySelector("[data-type]").textContent = hasResponse ? result.type : "—";
  panel.querySelector("[data-status]").textContent = hasResponse ? String(result.status) : "—";
  panel.querySelector("[data-body]").textContent = isOpaque ? "読み取り不可" : result.body ?? "—";
}

async function runObservation(panel) {
  const caseName = panel.dataset.case;
  for (const button of Buttons) {
    button.disabled = true;
  }
  showResult(panel, {kind: "pending"});

  try {
    const result = caseName === "same-origin"
      ? await observeFetch({mode: "same-origin"})
      : await observeInFrame(caseName);
    showResult(panel, result);
  } finally {
    for (const button of Buttons) {
      button.disabled = false;
    }
  }
}

for (const panel of Panels) {
  panel.querySelector("button").addEventListener("click", () => void runObservation(panel));
}

sandbox内で実行するfetch ​

"use strict";

const FrameCases = {
  cors: {mode: "cors"},
  "no-cors": {mode: "no-cors"},
  preflight: {mode: "cors", headers: {"X-Study-Demo": "1"}},
};

async function runFrameObservation() {
  const caseName = location.hash.slice(1);
  if (window.parent === window || window.origin !== "null" || !Object.hasOwn(FrameCases, caseName)) {
    return;
  }

  const result = await observeFetch(FrameCases[caseName]);
  // 配信URLのオリジンが、親ページのオリジンに一致します。
  window.parent.postMessage({
    message: ObservationMessage,
    caseName,
    result,
  }, new URL(location.href).origin);
}

void runFrameObservation();

ローカルサーバーの応答 ​

python
"""Serve the CORS observation files on loopback with a selectable fixture policy."""

import argparse
from functools import partial
from http.server import SimpleHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path


PAYLOAD_PATH = "/payload.txt"
ASSET_PATHS = {
    "/index.html",
    "/styles.css",
    "/observe.js",
    "/main.js",
    "/frame.html",
    "/frame.js",
    PAYLOAD_PATH,
}


class ObservationHandler(SimpleHTTPRequestHandler):
    def send_head(self):
        if self.path == "/":
            self.path = "/index.html"
        if self.path not in ASSET_PATHS:
            self.send_error(404)
            return None
        return super().send_head()

    def do_OPTIONS(self):
        if self.path != PAYLOAD_PATH:
            self.send_error(404)
            return
        if (
            self.server.policy != "preflight"
            or not self.headers.get("Origin")
            or self.headers.get("Access-Control-Request-Method") != "GET"
            or self.headers.get("Access-Control-Request-Headers", "").lower() != "x-study-demo"
        ):
            self.send_error(403)
            return

        self.send_response(204)
        self.send_header("Access-Control-Allow-Origin", "*")
        self.send_header("Access-Control-Allow-Methods", "GET")
        self.send_header("Access-Control-Allow-Headers", "X-Study-Demo")
        self.send_header("Access-Control-Max-Age", "0")
        self.end_headers()

    def end_headers(self):
        if (
            self.path == PAYLOAD_PATH
            and self.command in {"GET", "HEAD"}
            and self.server.policy != "deny"
        ):
            self.send_header("Access-Control-Allow-Origin", "*")
        self.send_header("Cache-Control", "no-store")
        super().end_headers()

    def log_request(self, code="-", size="-"):
        headers = (
            "Origin",
            "Access-Control-Request-Method",
            "Access-Control-Request-Headers",
            "X-Study-Demo",
        )
        details = " ".join(
            f"{name}={self.headers[name]!r}" for name in headers if name in self.headers
        )
        print(f"{self.command} {self.path!r} -> {code} {details}".rstrip(), flush=True)


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--port", type=int, default=4176)
    parser.add_argument("--policy", choices=["deny", "read", "preflight"], default="deny")
    args = parser.parse_args()

    handler = partial(ObservationHandler, directory=Path(__file__).resolve().parent)
    with ThreadingHTTPServer(("127.0.0.1", args.port), handler) as server:
        server.policy = args.policy
        print(f"http://127.0.0.1:{server.server_port}/index.html ({args.policy})", flush=True)
        try:
            server.serve_forever()
        except KeyboardInterrupt:
            pass


if __name__ == "__main__":
    main()
